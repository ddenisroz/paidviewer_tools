# 🚀 Тестирование с реальным Twitch аккаунтом

## 📋 Быстрая настройка

### 1. Создайте приложение Twitch
1. Перейдите на https://dev.twitch.tv/console/apps
2. Нажмите "Register Your Application"
3. Заполните:
   - **Name**: TTS_TTV Bot
   - **OAuth Redirect URLs**: `http://localhost:5173/auth/callback`
   - **Category**: Chat Bot
4. Нажмите "Create"
5. **Скопируйте Client ID и Client Secret**

### 2. Получите токен бота
1. Перейдите на https://twitchtokengenerator.com/
2. Выберите "Custom Scope Token"
3. Введите ваш **Client ID** из шага 1
4. Выберите скопы:
   - `chat:read`
   - `chat:edit` 
   - `moderator:read:chatters`
   - `moderator:manage:chat_messages`
5. **Скопируйте токен** (начинается с `oauth:`)

### 3. Узнайте имя бота
1. Войдите в аккаунт, который будет ботом
2. **Скопируйте имя пользователя** (username)

### 4. Настройте .env файл
```bash
# Скопируйте пример
copy test.env.example .env

# Отредактируйте .env файл
notepad .env
```

Заполните все поля:
```env
# Twitch API
TWITCH_CLIENT_ID=ваш_client_id_здесь
TWITCH_CLIENT_SECRET=ваш_client_secret_здесь
TWITCH_BOT_TOKEN=oauth:ваш_токен_здесь
TWITCH_BOT_USERNAME=имя_вашего_бота

# JWT Secret (сгенерировать)
SECRET_KEY=сгенерированный_jwt_ключ
```

### 5. Установите зависимости
```bash
pip install twitchio aiohttp fastapi uvicorn
```

### 6. Запустите тестовую систему
```bash
start_test_real.bat
```

## 🎯 Тестирование

### 1. Откройте дашборд
- Перейдите на http://localhost:5173
- Войдите в систему

### 2. Подключитесь к каналу
- Введите **реальное название вашего Twitch канала**
- Бот подключится к каналу

### 3. Тестируйте команды в чате
- `!test` - проверить работу бота
- `!tts Привет всем!` - синтез речи
- `!mute username` - заглушить пользователя
- `!unmute username` - разглушить пользователя

## 🔧 Команды бота

| Команда | Описание | Пример |
|---------|----------|--------|
| `!test` | Проверка работы бота | `!test` |
| `!tts <текст>` | Синтез речи | `!tts Привет!` |
| `!mute <пользователь>` | Заглушить пользователя | `!mute username` |
| `!unmute <пользователь>` | Разглушить пользователя | `!unmute username` |

## 📊 Проверка работы

```
TTS запрос: Привет всем! от username
✅ TTS успешно обработан: 'Привет всем!'
```

### Логи TTS сервиса:
```
🎤 TTS запрос: 'Привет всем!' для канала your_channel
✅ TTS успешно обработан: 'Привет всем!'
```

## 🚀 Переход в продакшн

После тестирования просто:
1. Скопируйте настройки из `.env` в `bot-service/.env`
2. Запустите продакшн сервисы вместо тестовых
3. Всё готово!

## ❗ Устранение проблем

### Бот не подключается:
- Проверьте токен в .env файле
- Убедитесь, что канал существует
- Проверьте права бота в канале

### TTS не работает:
- Проверьте, что TTS сервис запущен на порту 8001
- Проверьте логи TTS сервиса

### Ошибки в консоли:
- Проверьте, что все сервисы запущены
- Проверьте порты 8000, 8001, 5173
