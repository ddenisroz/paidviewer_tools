# 🔀 Разделение Глобальных и Пользовательских Голосов

**Дата:** 31 октября 2025  
**Статус:** ✅ **РЕАЛИЗОВАНО**

---

## 📊 Обзор

На странице `/dashboard/tts/voices` теперь реализовано **строгое разделение** между глобальными и пользовательскими голосами с разными правами доступа и возможностями управления.

---

## 🎯 Два Типа Голосов

### 1. 🌐 Глобальные Голоса (`voice_type='global'`)

**Характеристики:**
- ✅ Доступны **всем пользователям** в системе
- ✅ Загружаются **только через админку** (`/dashboard/dolbaebadmintts`)
- ✅ Сохраняются в `audio/voices/global/`
- ⚠️ **Ограничения для пользователей:**
  - ❌ Нельзя удалять
  - ❌ Нельзя переименовывать
  - ❌ Нельзя редактировать референсный текст
  - ❌ Нельзя перетранскрибировать
  - ✅ Можно настраивать параметры синтеза **только для своего профиля**

**Настройки применяются только к профилю пользователя:**
- Когда пользователь изменяет `cfg_strength` или `speed_preset` глобального голоса, изменения сохраняются только для его профиля
- Другие пользователи продолжают видеть дефолтные настройки или свои личные настройки

---

### 2. 👤 Пользовательские Голоса (`voice_type='user'`)

**Характеристики:**
- ✅ Доступны **только владельцу** (пользователю, который их загрузил)
- ✅ Загружаются через страницу `/dashboard/tts/voices`
- ✅ Сохраняются в `audio/voices/user/{user_id}/`
- ✅ **Полный контроль:**
  - ✅ Можно удалять
  - ✅ Можно переименовывать
  - ✅ Можно редактировать референсный текст
  - ✅ Можно перетранскрибировать
  - ✅ Настройки сохраняются глобально для голоса

## 🔌 API Endpoints

### Backend (`F5_tts` provider API)

| Endpoint | Метод | Описание | Тип голосов |
|----------|-------|----------|-------------|
| `/api/voices/global` | GET | Получить глобальные голоса | global |
| `/api/tts/user/voices/{user_id}` | GET | Получить голоса пользователя | user |
| `/api/admin/voices/upload` | POST | Загрузить глобальный голос (админка) | global |
| `/api/tts/user/voices/upload` | POST | Загрузить пользовательский голос | user |
| `/api/tts/user/voices/{voice_id}` | DELETE | Удалить голос | user only |
| `/api/tts/user/voices/{voice_id}/rename` | PUT | Переименовать голос | user only |
| `/api/tts/user/voices/{voice_id}/retranscribe` | POST | Перетранскрибировать | user only |
| `/api/tts/user/voices/{voice_id}/settings` | PUT | Обновить настройки | global/user |

## 🎯 Логика Ограничений

### Проверки на Frontend

```javascript
// Удаление - только для пользовательских
if (voiceType === 'global') {
    addToast({ type: 'error', message: 'Вы не можете удалять глобальные голоса.' });
    return;
}

// Переименование - только для пользовательских
if (currentVoice.voice_type === 'global') {
    addToast({ type: 'error', message: 'Вы не можете переименовывать глобальные голоса.' });
    return;
}

// Перетранскрибация - только для пользовательских
if (currentVoice.voice_type === 'global') {
    addToast({ type: 'error', message: 'Вы не можете изменять глобальные голоса.' });
    return;
}
```

### UI Ограничения

```javascript
// Кнопка удаления только для пользовательских
{whitelistStatus?.can_manage_voices && voice.voice_type === 'user' && (
    <Button variant="destructive" onClick={() => handleDelete(voice.id)}>
        <Trash2 />
    </Button>
)}

// Кнопка переименования только для пользовательских
{currentVoice?.voice_type === 'user' && (
    <Button onClick={handleRenameVoice}>
        <Edit /> Переименовать
    </Button>
)}

// Поле референсного текста disabled для глобальных
<Textarea
    value={currentVoice.reference_text || ''}
    disabled={currentVoice.voice_type === 'global'}
/>

// Кнопка перетранскрибации только для пользовательских
{currentVoice.voice_type === 'user' && (
    <Button onClick={handleTranscribe}>
        Перетранскрибировать
    </Button>
)}
```

## 📝 Примечания

1. **Настройки глобальных голосов:**
   - Когда пользователь изменяет настройки глобального голоса, они применяются только к его профилю
   - Backend должен сохранять персональные настройки в отдельной таблице или в JSON поле пользователя

2. **Whitelist:**
   - Доступ к F5-TTS (и загрузке голосов) требует наличия в whitelist
   - Гости могут видеть только глобальные голоса (если канал в whitelist)

3. **Админка:**
   - Только администраторы могут загружать глобальные голоса
   - Админка находится по адресу `/dashboard/dolbaebadmintts`
