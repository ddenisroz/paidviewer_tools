## 📊 Обзор

Админ-панель (`/dashboard/dolbaebadmintts`) предоставляет **полный контроль** над всеми голосами в системе - как глобальными, так и пользовательскими.

---

## 🎯 Возможности Админа

### 1. 👁️ Просмотр Всех Голосов

Админ видит **ВСЕ** голоса в системе, разделённые на **две секции** (без вкладок):

**👤 Пользовательские голоса (верхняя секция)**
- Принадлежат конкретным пользователям
- Админ может их просматривать, редактировать и удалять
- Сохраняются в `audio/voices/user/{user_id}/`
- Доступен фильтр по пользователю (выпадающий список)
- Показываются с подзаголовком "Пользовательские голоса"

**🌐 Глобальные голоса (нижняя секция)**
- Доступны всем пользователям
- Админ может их создавать, редактировать и удалять
- Сохраняются в `audio/voices/global/`
- Показываются с подзаголовком "Глобальные голоса"
- Разделитель между секциями для визуального разделения

**Интерфейс:**
- Нет вкладок ("Все", "Глобальные", "Пользовательские")
- Две секции на одной странице
- Верхняя секция: пользовательские голоса
- Нижняя секция: глобальные голоса

---

### 2. 📤 Загрузка Голосов

При загрузке админ **выбирает тип голоса**:

```
┌────────────────────────────────────┐
│  Загрузка нового голоса            │
├────────────────────────────────────┤
│  Файл: [Выбрать файл]              │
│  Имя голоса: [________]            │
│                                    │
│  Тип голоса:                       │
│  ◉ Глобальный (для всех)           │ ← По умолчанию
│  ○ Пользовательский                │
│                                    │
│  [Если выбран пользовательский:]   │
│  Пользователь: [Выбрать ▼]         │
│                                    │
│  [Отмена]  [Загрузить]             │
└────────────────────────────────────┘
```

#### Глобальный голос
- Endpoint: `POST /api/admin/voices/upload`
- Автоконвертация в WAV 48kHz Mono 16-bit
- Автотранскрибация через Whisper
- Доступен всем пользователям

#### Пользовательский голос (от имени пользователя)
- Endpoint: `POST /api/tts/user/voices/upload`
- Админ выбирает пользователя из списка
- Автоконвертация и транскрибация
- Доступен только выбранному пользователю

---

### 3. ⚙️ Полное Управление Настройками

Админ имеет **расширенные возможности** для настройки любого голоса:

**Для ВСЕХ голосов (глобальных и пользовательских):**

✅ **Референсный текст**
- Редактирование вручную
- Перетранскрибация аудиофайла
- Кнопка "Перетранскрибировать" запускает Whisper

✅ **Настройки синтеза**
- Стабильность синтеза (`cfg_strength`): 0.1 - 10.0
- Скорость речи (`speed_preset`): очень медленный → очень быстрый

✅ **Тестирование**
- Ввод тестового текста
- Выбор параметров для теста
- Прослушивание результата

✅ **Управление**
- Переименование голоса
- Удаление голоса
- Включение/выключение голоса

## 📦 Структура Кода

### Frontend

**`frontend/src/components/admin/VoiceManagement.jsx`**

```javascript
const handleUpload = async (event) => {
    const formData = new FormData();
    formData.append('file', uploadFile);
    formData.append('voice_name', voiceName.trim());
    
    if (ownerId === 'user') {
        // Загрузка пользовательского голоса от имени юзера
        formData.append('user_id', selectedUserId);
        await uploadUserVoice(selectedUserId, formData);
    } else {
        // Загрузка глобального голоса
        await uploadVoice(formData);
    }
};
```

### Backend

**`f5-tts-service/admin_api.py`**
- `GET /api/admin/voices` - получить ВСЕ голоса (глобальные + пользовательские)
- `POST /api/admin/voices/upload` - загрузить глобальный голос
- `DELETE /api/admin/voices/{id}` - удалить любой голос
- `PUT /api/admin/voices/{id}/rename` - переименовать любой голос

**`f5-tts-service/api_endpoints.py`**
- `POST /api/tts/user/voices/upload` - загрузить пользовательский голос (используется админом от имени юзера)

## 🔄 Workflow Админа

### Загрузка Глобального Голоса

1. Админ открывает `/dashboard/dolbaebadmintts`
2. Нажимает "Загрузить голос"
3. Выбирает файл (MP3, WAV, FLAC, и т.д.)
4. Вводит имя голоса
5. Оставляет "Глобальный (для всех)"
6. Нажимает "Загрузить"
7. **Результат:** Голос создаётся с `voice_type='global'`, доступен всем

### Загрузка от Имени Пользователя

1. Админ открывает `/dashboard/dolbaebadmintts`
2. Нажимает "Загрузить голос"
3. Выбирает файл
4. Вводит имя голоса
5. Выбирает "Пользовательский"
6. В выпадающем списке выбирает пользователя
7. Нажимает "Загрузить"
8. **Результат:** Голос создаётся с `voice_type='user'`, `owner_id={selected_user_id}`, доступен только этому юзеру

### Редактирование Любого Голоса

1. Админ находит голос в списке (глобальный или пользовательский)
2. Нажимает "Настройки"
3. **Может:**
   - Редактировать референсный текст
   - Перетранскрибировать аудио
   - Изменить параметры синтеза
   - Протестировать голос
   - Переименовать
   - Сохранить изменения
4. **Результат:** Изменения применяются глобально

### Удаление Любого Голоса

1. Админ находит голос в списке
2. Нажимает кнопку удаления (корзина)
3. Подтверждает удаление
4. **Результат:** Голос удаляется из БД и файловой системы
