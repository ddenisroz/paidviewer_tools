# Backlog Docs

These files are historical notes, audits, and temporary planning artifacts.

They are not runtime documentation and do not describe the current source of truth.

Use this folder only for:
- past audits
- migration backlogs
- temporary issue lists

If a document here becomes relevant for current implementation, move or rewrite it into:
- `docs/setup/`
- `docs/architecture/`
- `docs/guides/`
- `docs/features/`
