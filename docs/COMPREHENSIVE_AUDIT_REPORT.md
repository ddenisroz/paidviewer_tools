## 1. Синхронизация кнопок и состояний

### ✅ Статус: **ОТЛИЧНО**

**Механизмы синхронизации:**

1. **React Query для глобальных состояний:**
   - `QuickActionsBar` использует `useQuery` с `refetchInterval: 30000` для синхронизации TTS статуса
   - `TtsMainPage` использует тот же `queryKey: ['tts-status']` для синхронизации
   - Кэш инвалидируется при изменениях через `queryClient.invalidateQueries`

2. **Custom Events для межкомпонентной синхронизации:**
   - `tts-status-changed` - для синхронизации TTS статуса
   - `drops-config-changed` - для синхронизации настроек Drops
   - `tts-settings-changed` - для синхронизации настроек платформ TTS

3. **WebSocket для real-time синхронизации:**
   - `SharedWebSocketManager` с Leader Election для синхронизации между вкладками
   - Heartbeat механизм с ping/pong для проверки активности лидера
   - Автоматическое переподключение при потере соединения

4. **localStorage для персистентности:**
   - Кэширование настроек в localStorage для быстрой инициализации
   - Версионирование данных для защиты от race conditions

**Проблемы не обнаружены:**
- ✅ Все кнопки синхронизированы через единые источники данных
- ✅ Нет рассинхронизации между компонентами

## 6. Система Drops

### ✅ Статус: **ОТЛИЧНО**

**Как работает система Drops:**

### 6.1. Архитектура

```
ТРИГГЕР → ПРОВЕРКА УСЛОВИЙ → ОПРЕДЕЛЕНИЕ КАЧЕСТВА → ВЫБОР НАГРАДЫ → СОХРАНЕНИЕ → ОТПРАВКА В ВИДЖЕТ
```

### 6.2. Типы Drops

#### **Streak Drops (Стрик-лутбоксы)**
- **Триггер:** Зритель написал сообщение в чат
- **Условия:**
  - `streak_enabled_twitch` или `streak_enabled_vk` = true
  - Прошел новый день (24 часа с last_activity)
  - `streak.messages_this_stream >= streak_messages_required`
  - `streak.current_streak >= streak_days_common`
- **Качество:** Определяется по дням стрика (common/rare/epic/legendary)

#### **Donation Drops (Донат-лутбоксы)**
- **Триггер:** Зритель сделал донат через DonationAlerts
- **Условия:**
  - `donation_enabled = true`
  - `donation_amount >= donation_amount_common`
- **Качество:** Определяется по сумме доната

#### **Mythical Drops (Мифические сундуки)**
- **Триггер:** Случайный интервал (min_interval_hours - max_interval_hours)
- **Условия:**
  - `mythical_enabled = true`
  - Стрим онлайн
  - Окно активности открыто (window_duration_minutes)
  - Донат >= mythical_donation_amount
- **Качество:** Всегда legendary

### 6.3. Определение награды

1. **Определение качества:**
   - По формуле на основе триггера (дни стрика / сумма доната)

2. **Выбор награды:**
   - Фильтрация по `quality_id` и `is_active = true`
   - Weighted random выбор на основе `weight`
   - Проверка доступности награды

3. **Сохранение:**
   - Запись в `DropsHistory`
   - Обновление статистики
   - Отправка в виджет через WebSocket
