## 🎯 Ключевые изменения

### 1. Компактность блока "Аудио"

| Параметр | До | После |
|----------|-------|--------|
| min-height | 200px | auto (адекватно контенту) |
| Пустое место | 60-70% | 0% |
| Высота при наличии слайдера | ~200px | ~100px |
| Высота в OBS режиме | N/A | ~80px |

**Результат**: Экономия ~100-120px вертикального пространства ✅

---

### 2. Размещение OBS Browser Source URL

| Параметр | До | После |
|----------|-------|--------|
| Размещение | Отдельная карточка | Встроена в "Вывод звука" |
| Высота на странице | +180px | +60px (в OBS режиме) |
| Видимость | Всегда (когда OBS) | Только при listeningMode='obs' |
| Логическое связь с режимом | Слабая | Сильная ✅ |

**Результат**: Экономия ~120px, лучшая логическая связь ✅

---

### 3. Управление звуком в разных режимах

#### Website режим:
```
┌─────────────────────────┐
│ АУДИО                   │
├─────────────────────────┤
│ Громкость: 50%          │
│ ┌───────────────────┐   │
│ │ ════════ (slider) │   │
│ └───────────────────┘   │
└─────────────────────────┘
```

#### OBS режим:
```
┌─────────────────────────┐
│ АУДИО                   │
├─────────────────────────┤
│ Громкость настраивается │
│ в OBS                   │
│                         │
│ (просто информация)     │
└─────────────────────────┘
```

**Результат**: Ясно объясняет пользователю, где настраивается громкость ✅
