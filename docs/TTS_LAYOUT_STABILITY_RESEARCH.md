# Исследование проблемы динамических размеров карточек TTS страницы
**Дата**: 2025-11-06  
**Статус**: 🔍 Исследование завершено, решение предложено

## 📋 Проблема

При изменении настроек или появлении новых элементов карточки меняют свою высоту, что приводит к:
- ❌ Несовпадению высот левой и правой колонок
- ❌ "Прыгающей" верстке при переключении режимов
- ❌ Плохому UX (пользователь теряет ориентацию)

---

## 💡 Предложенные решения

### Решение #1: Резервирование места (Reserved Space Pattern) ✅ РЕКОМЕНДУЕТСЯ

**Принцип**: Всегда резервировать место для условных элементов, даже когда они скрыты.

**Преимущества**:
- ✅ Верстка не двигается
- ✅ Плавные переходы через opacity
- ✅ Простота реализации

**Недостатки**:
- ⚠️ Может быть пустое место (но это лучше чем прыгающая верстка)

**Пример (уже реализовано для OBS)**:
```jsx
{/* OBS Widget Link Section - Always reserves space */}
<div className={`mt-auto space-y-2 pt-3 transition-all ${
    listeningMode === 'obs' 
        ? 'opacity-100' 
        : 'opacity-0 h-[120px] pointer-events-none'
}`}>
    {/* OBS content */}
</div>
```

---

### Решение #2: Фиксированные минимальные высоты

**Принцип**: Установить `min-h` для всех карточек и секций.

**Преимущества**:
- ✅ Простота
- ✅ Предсказуемость

**Недостатки**:
- ⚠️ Может быть слишком много пустого места
- ⚠️ Не работает для растущих списков

**Пример**:
```jsx
<Card className="min-h-[500px]">
    {/* Content */}
</Card>
```

---

### Решение #3: CSS Grid с фиксированными строками

**Принцип**: Использовать CSS Grid с фиксированными высотами строк.

**Преимущества**:
- ✅ Полный контроль над размерами
- ✅ Адаптивность

**Недостатки**:
- ⚠️ Сложность реализации
- ⚠️ Может быть негибким

---

### Решение #4: Комбинированный подход ✅ ЛУЧШИЙ

**Принцип**: Комбинация резервирования места + фиксированных минимальных высот.

**Стратегия**:
1. **Условные элементы** → Резервирование места (opacity pattern)
2. **Карточки** → Фиксированные минимальные высоты
3. **Растущие списки** → Максимальная высота + скролл
