### 4. Улучшение useAutoSave

#### Проблема
Ручной `setTimeout` в `useAutoSave`:
- Ручная очистка таймеров
- Риск утечек памяти

#### Решение
Использует `useDebouncedCallback` из библиотеки:

**До:**
```javascript
const timeoutRef = useRef(null);
timeoutRef.current = setTimeout(() => { ... }, delay);
```

**После:**
```javascript
const debouncedSave = useDebouncedCallback(() => { ... }, delay);
```

**Преимущества:**
- ✅ Автоматическая очистка — библиотека управляет таймерами
- ✅ Меньше кода — убрано ~15 строк

## 🔍 Детали изменений

### Замена debounce на библиотеку

**До:**
```javascript
export const useDebounce = (value, delay = 300) => {
    const [debouncedValue, setDebouncedValue] = useState(value);
    useEffect(() => {
        const timer = setTimeout(() => {
            setDebouncedValue(value);
        }, delay);
        return () => clearTimeout(timer);
    }, [value, delay]);
    return debouncedValue;
};
```

**После:**
```javascript
import { useDebounce as useDebounceValue } from 'use-debounce';
export const useDebounce = (value, delay = 300) => {
    return useDebounceValue(value, delay);
};
```

**Результат:** -24 строки, +надежность

### Создание хуков для таймеров

**До:**
```javascript
useEffect(() => {
    const interval = setInterval(fetchStats, 30000);
    return () => clearInterval(interval);
}, []);
```

**После:**
```javascript
const { clear } = useInterval(() => {
    fetchStats();
}, 30000);
```

**Результат:** Чище код, автоматическая очистка

### Валидация с Zod

**До:**
```javascript
email: (value) => {
    if (!value) return null;
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return emailRegex.test(value) ? null : 'Введите корректный email';
}
```

**После:**
```javascript
export const emailSchema = z.string().email('Введите корректный email');
```

**Результат:** Типобезопасность, переиспользование
