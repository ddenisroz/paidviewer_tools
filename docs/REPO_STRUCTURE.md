# Repository Structure and Hygiene

This page explains what is part of the product and what is local noise.

## Runtime-Critical Paths

| Path | Purpose | Touch when |
|---|---|---|
| `bot_service/` | Main backend: API, auth, services, repositories, models, startup lifecycle | Backend feature/fix/security work |
| `frontend/` | Main dashboard app (React + Vite) | UI/API integration work |
| `deploy/` | Compose files, nginx, production topology | Deployment or infra changes |
| `bot_service/alembic/` | DB migrations and schema history | DB model/schema changes |

## Operational but Not Runtime Logic

| Path | Purpose | Notes |
|---|---|---|
| `.github/workflows/` | CI checks and pipelines | Affects PR/build validation only |
| `docs/` | Architecture, setup, guides, API docs | No runtime behavior |
| `docs/backlog/` | Historical audit notes and temporary plans | Informational only, not source of truth |
| `scripts/` | Migrations and helper scripts | Ops/dev tooling |
| `scripts/dev/` | Diagnostics, one-off verification, cleanup helpers | Safe to ignore if not debugging |
| `.husky/` | Git hooks (pre-commit checks) | Dev workflow only |
| `.venv/` | Local Python environment | Machine-local only, not part of product source |

## Generated/Local Artifacts (Safe to Delete)

| Pattern | Source | Should be committed |
|---|---|---|
| `**/__pycache__/` | Python runtime/import cache | No |
| `.ruff_cache/` | Ruff | No |
| `.pytest_cache/` | Pytest | No |
| `pytest-cache-files-*` | Pytest temporary file cache directories | No |
| `.benchmarks/` | pytest-benchmark output | No |
| `.pytest_tmp/` | local smoke/runtime scratch space | No |
| `tmp/`, `bot_service/tmp/` | temporary logs, upstream dumps, pytest temp dirs | No |
| `artifacts/` | local run outputs | No |
| `frontend/dist/` | `vite build` output | No |
| `logs/*.log` | local service logging | No |
| `logs/*.json` | local debug/chat history dumps | No |
| `.venv/` | local Python packages and bytecode | No |
| `.playwright*/`, `playwright-report/`, `*.har` | browser/e2e diagnostics | No |

## One-Line Rule

If a path is generated by lint/test/build/runtime, it is not business logic and can be cleaned safely.

## Cleanup

```powershell
.\scripts\prepare-release.ps1
.\scripts\prepare-release.ps1 -ApplyCleanup
.\scripts\prepare-release.ps1 -ApplyCleanup -IncludeVenvCaches
```
