# Претензии и запросы пользователя

## Дата: 2025-11-09

### Проблемы с поиском награды TTS

1. **Награда TTS не находится после перезапуска бота**
   - Награда существует на VK Live, была создана через это же меню
   - Система не находит существующую награду
   - Подход в поиске награды существующей за озвучку неверный
   - Не находит награду которая есть сейчас на vk live

### Проблемы с интерфейсом Drops - Стрик

2. **Тоглы стриков не кликабельны**
   - В drops стрик включены twitch и vk live и нельзя на них тыкнуть
   - Тоглы показываются как включенные, но disabled

3. **Шорткат работает только для одной платформы**
   - Шорткат включает и отключает только twitch
   - Должен работать для обеих платформ (Twitch и VK)

4. **Неправильная привязка системы стриков**
   - Система должна быть привязана не к дням, стример может стримить через день
   - Должна быть привязана к его стримам (т.е. засчитывать дни только тогда, когда стрим онлайн)

5. **Некорректные подписи в интерфейсе**
   - Убрать слово "Стрик" перед настройкой дней стрика
   - Убрать подпись "Дни для наград" из заголовка StreakSettings

6. **Неопрятная статистика**
   - Разные отступы, разные шрифты
   - Где-то просто числа, где-то с подписью
   - Нужно сделать единообразие

### Проблемы с интерфейсом Drops - Донат

7. **Заблокированные тоглы донатных дропс**
   - Тоглы включения донатных дропс заблокированы
   - Нельзя их включить даже когда DonationAlerts подключен

8. **Автоматическое включение donation drops**
   - После того как нажата кнопка подключения и она перенаправила на donationalerts, а потом обратно с успешным подключением, то она должна сама включить donate drops

9. **Некорректные подписи в интерфейсе**
   - Убрать слово "Донат" перед настройкой сундуков
   - Убрать подпись "Настройки донатов" из заголовка DonationSettings

### Проблемы с мифическим сундуком

10. **Неудобные настройки мифического сундука**
    - Настройки мифического сундука сделать тоже чтоб было удобнее настраивать (не только ползунками)
    - Добавить инпуты для прямого ввода значений

11. **Некорректное название**
    - Переименовать "Мифический lootbox" в "Мифический drops"

12. **Мифический сундук должен быть только когда стрим онлайн**
    - Возможность получать мифический сундук должна быть только когда стрим онлайн

13. **Виджет для OBS**
    - Нужен виджет для obs который показывал бы этот сундук и остаток таймера когда ивент запущен
