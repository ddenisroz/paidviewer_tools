# 🎮 Как использовать унифицированные команды !game и !title

**Для стримеров** | **Быстрая инструкция**

---

## 🎯 Что это?

Теперь команды `!game` и `!title` в чате могут **автоматически обновлять обе платформы** (Twitch **И** VK Live) одновременно!

---

## ⚙️ Как включить?

### Шаг 1: Перейти на главную страницу

Откройте дашборд: **`/dashboard`**

### Шаг 2: Найти карточки управления стримом

На главной странице вы увидите две карточки:
- 📝 **"Смена названия"**
- 🎮 **"Смена категории"**

### Шаг 3: Включить объединение

В каждой карточке есть toggle **"Объединить поля"** (он появляется только если у вас подключены **Twitch И VK Live**):

```
┌──────────────────────────────────────┐
│  📝 Смена названия                   │
├──────────────────────────────────────┤
│  🔗 Объединить поля         [ON/OFF] │ ← Включите этот toggle
│                                      │
│  [Twitch] Мой стрим                  │
│  [VK]     Мой стрим                  │
└──────────────────────────────────────┘
```

**Аналогично для карточки "Смена категории".**

---

## 🚀 Как пользоваться командами?

### Команда `!game`

**Что делает:** Меняет игру/категорию на стриме

**Синтаксис:**
```
!game <название игры>
```

**Примеры:**
```bash
!game Dead by Daylight
!game dbd                    # тоже работает (алиас)
!game Just Chatting
!game общение                # VK/RU аналог
!game cs2                    # Counter-Strike 2
```

**Результат:**
- ✅ Если **объединение включено**: Игра изменится на **Twitch И VK Live**
- ✅ Если **объединение выключено**: Игра изменится только на той платформе, где вызвана команда

---

### Команда `!title`

**Что делает:** Меняет название стрима

**Синтаксис:**
```
!title <новое название>
```

**Примеры:**
```bash
!title Субботний стрим! Играем в DBD
!title [RU] Дота 2 с подписчиками
!title 🔴 LIVE - Общаемся и играем
```

**Результат:**
- ✅ Если **объединение включено**: Название изменится на **Twitch И VK Live**
- ✅ Если **объединение выключено**: Название изменится только на той платформе, где вызвана команда

---

## 📱 Что увидит чат?

Бот всегда сообщит, на каких платформах произошло обновление:

### ✅ С объединением (обе платформы подключены и toggle включен):
```
@username: !game dbd
Бот: ✅ Игра изменена на: Dead by Daylight (Twitch и VK Live)
```

### ✅ Без объединения (toggle выключен):
```
@username: !title Новый стрим
Бот: ✅ Название изменено на: Новый стрим (Twitch)
```

### ✅ Только одна платформа подключена:
```
@username: !game cs2
Бот: ✅ Игра изменена на: Counter-Strike 2 (VK Live)
```

## ❓ FAQ

### **В: Можно ли включить только объединение названий, но не категорий?**
**О:** Да! Toggles работают **независимо**. Вы можете включить один, оба, или ни одного.

---

### **В: Работает ли это для гостей?**
**О:** Нет, эта функция доступна только для **авторизованных пользователей** с подключенными платформами.

---

### **В: Что если у меня подключена только одна платформа (например, только Twitch)?**
**О:** Команда будет работать **только для Twitch**. Toggle объединения не появится, так как он требует наличия **двух** подключенных платформ.

---

### **В: Можно ли вызвать команду из чата VK и обновить Twitch?**
**О:** Да! Если объединение включено, команда, вызванная на **любой** платформе, обновит **обе**.

---

### **В: Что если я напишу название игры на русском, а у меня Twitch (английский)?**
**О:** Система использует **умный маппинг** с 320+ алиасами и переводами. Например:
- `общение` → `Just Chatting`
- `дота` → `Dota 2`
- `майнкрафт` → `Minecraft`

Это работает автоматически! 🎉

## 🔧 Настройка (детально)

### Где хранятся настройки?

Настройки сохраняются в базе данных в таблице `users`:
- `combine_categories` - для команды `!game`
- `combine_titles` - для команды `!title`

### Как проверить текущее состояние?

Просто посмотрите на toggles на главной странице `/dashboard`. Если они **включены** (зелёные), значит объединение активно.

---

## 💡 Совет

Если вы **постоянно** стримите на обе платформы, рекомендуется **всегда держать toggles включенными**. Это обеспечит консистентность названий и категорий на обеих площадках.
