# 📋 Краткая сводка проекта TTS_TTV_0.02

## 🎯 **Описание проекта**
Многоплатформенная система TTS (Text-to-Speech) для стримеров с поддержкой Twitch и VK Live, включающая озвучку сообщений чата, управление голосами, фильтрацию контента и интеграцию с внешними сервисами.

## 🏗️ **Архитектура проекта**

### 🔧 **Бэкенд (bot_service)**
- **Технологии:** FastAPI, SQLAlchemy, Alembic, TwitchIO
- **Порт:** 8000
- **База данных:** SQLite
- **Основные модули:**
  - `bots/` - боты для Twitch и VK Live
  - `api/` - REST API endpoints
  - `services/` - бизнес-логика
  - `core/` - база данных и подключения
  - `auth/` - аутентификация

### 🎨 **Фронтенд (frontend)**
- **Технологии:** React, Vite, Tailwind CSS, Lucide React
- **Порт:** 5173
- **Основные страницы:**
  - `/tts` - управление TTS настройками
  - `/dashboard` - общая панель управления
  - `/admin` - административная панель

### 🔊 **TTS Сервис (tts_service)**
- **Технологии:** FastAPI, F5-TTS, PyTorch
- **Порт:** 8001
- **Функции:** Синтез речи, управление голосами, конвертация аудио

## 🚀 **Ключевые функции**

### 🎤 **TTS Система**
- Озвучка сообщений чата в реальном времени
- Поддержка множественных голосов (глобальные + пользовательские)
- Настройки громкости и скорости речи
- Фильтрация слов и контента
- Настройки озвучки смайликов (7TV, Twitch)

### 🤖 **Боты**
- **Twitch Bot:** Обработка команд и сообщений чата
- **VK Live Bot:** Интеграция с VK Live платформой
- **Команды:** Управление TTS, YouTube, настройки канала

### 🎵 **YouTube Интеграция**
- Воспроизведение видео в OBS через WebSocket
- Управление очередью видео
- Настройки громкости

### 🎁 **Дополнительные системы**
- **Лутбоксы:** Система наград для зрителей
- **Психологический анализ:** AI-анализ личности пользователей
- **DonationAlerts:** Интеграция с донатами
- **Мониторинг:** Отслеживание ресурсов сервера

## 🗄️ **База данных**

### 📊 **Основные таблицы**
- `users` - пользователи системы
- `tts_settings` - настройки TTS
- `filtered_words` - заблокированные слова
- `chat_messages` - история сообщений
- `psychology_analysis` - результаты AI-анализа
- `bot_commands` - команды ботов

### 🔄 **Миграции**
- Alembic для управления схемой БД
- Автоматические миграции при запуске
- Резервное копирование данных

## 🔐 **Аутентификация**
- **JWT токены** для внутренней аутентификации
- **OAuth 2.0** для Twitch и VK Live
- **Cookie-based сессии** для веб-интерфейса
- **Роли пользователей:** admin, moderator, user, guest

## 🌐 **API Endpoints**

### 🎤 **TTS API**
- `GET/POST /api/tts/settings` - настройки TTS
- `GET/POST /api/tts/filtered-words` - фильтрация слов
- `GET/POST /api/tts/voices` - управление голосами
- `GET/POST /api/tts/volume` - настройки громкости

### 🤖 **Bot API**
- `GET/POST /api/commands` - команды ботов
- `GET/POST /api/stream/update` - обновление стрима
- `GET/POST /api/tts/enable` - включение TTS

### 🎁 **Дополнительные API**
- `GET/POST /api/lootbox/*` - система лутбоксов
- `GET/POST /api/support/*` - система поддержки
- `GET/POST /api/database/*` - управление БД

## 🚀 **Запуск проекта**

### 📋 **Требования**
- Python 3.8+
- Node.js 16+
- SQLite
- CUDA (для TTS)

### 🔧 **Установка**
```bash
# Бэкенд
cd bot_service
pip install -r requirements.txt
python main.py

# TTS Сервис
cd tts_service
pip install -r requirements.txt
python main.py

# Фронтенд
cd frontend
npm install
npm run dev
```

### ⚙️ **Конфигурация**
- Скопировать `.env.example` в `.env`
- Настроить токены OAuth
- Настроить базу данных
- Настроить CORS для фронтенда
