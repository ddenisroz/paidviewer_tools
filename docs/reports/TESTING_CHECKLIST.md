## 🧪 **План тестирования:**

### 1️⃣ **Тест API endpoints:**
```bash
# Получить список слов
GET /api/tts/filtered-words

# Добавить слово
POST /api/tts/filtered-words
{
  "word": "тест",
  "platform": "all"
}

# Удалить слово
DELETE /api/tts/filtered-words/{word_id}

# Проверить текст
POST /api/tts/filtered-words/check?text=тестовое сообщение&platform=all
```

### 2️⃣ **Тест фронтенда:**
1. **Откройте** `/tts` страницу
2. **Добавьте слово** в фильтр

4. **Удалите слово** - исчезло из списка
5. **Обновите страницу** - слова сохранились

### 3️⃣ **Тест интеграции с ботом:**

## 🔧 **Исправления во время тестирования:**

### ✅ **Проблема с API `/api/commands`:**
- **Ошибка:** `no such column: bot_commands.tags`
- **Причина:** Отсутствовала колонка `tags` в таблице `bot_commands`
- **Решение:** Добавлена колонка `tags VARCHAR` в таблицу
- **Статус:** ✅ Исправлено

### ✅ **Проблема с URL API:**
- **Ошибка:** `POST http://localhost:5173/api/tts/filtered-words 404`
- **Причина:** Фронтенд обращался к своему порту вместо бэкенда
- **Решение:** Изменены URL с `/api/tts/...` на `http://localhost:8000/api/tts/...`
- **Статус:** ✅ Исправлено

### ✅ **Настройка "Озвучивать 7TV смайлы":**
- **Проблема:** Настройка была только в UI, но не сохранялась в бэкенде
- **Решение:** 
  - Добавлен API `/api/tts/settings` для сохранения/загрузки настроек TTS
  - Интегрирована загрузка настроек при инициализации
  - Добавлено автоматическое сохранение при изменении переключателей
- **Статус:** ✅ Реализовано

### ✅ **Настройка "Озвучивать Twitch смайлы":**
- **Задача:** Добавить аналогичную настройку для Twitch смайликов
- **Решение:**

  - Добавлен UI переключатель для Twitch смайликов
  - Обновлен API для поддержки настройки `enableTwitch`
