## 📝 Конфигурация

### `tsconfig.json`
```json
{
  "compilerOptions": {
    "allowJs": true,        // Разрешить JS файлы
    "checkJs": true,        // Проверять JS файлы
    "strict": false,        // Начнем с false, затем включим
    "noEmit": true,         // Vite делает сборку
    "paths": {
      "@/*": ["./src/*"]    // Алиасы
    }
  }
}
```

### ESLint
- Поддержка `.ts` и `.tsx` файлов
- Правила для постепенной миграции
- Предупреждения вместо ошибок для `any`

## 📚 Полезные команды

### Проверка типов
```bash
npx tsc --noEmit              # Проверить все файлы
npx tsc --noEmit --watch      # Проверка в режиме watch
```

### ESLint
```bash
npm run lint                  # Проверить код
```

### Создание нового типа
1. Добавить тип в соответствующий файл в `types/`
2. Экспортировать из `types/index.d.ts`
3. Использовать в JSDoc: `@type {import('./types').User}`
