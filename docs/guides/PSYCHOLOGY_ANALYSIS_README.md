# 🧠 Психологический анализ пользователей

## Описание
Команда `!about <пользователь>` анализирует психологический портрет пользователя на основе его сообщений в чате за последние 30 дней с помощью ИИ.

## Возможности
- ✅ Анализ на основе реальных сообщений пользователя
- ✅ ИИ анализ через Hugging Face API
- ✅ Защита от спама (кулдаун 30 секунд)
- ✅ Кэширование результатов (24 часа)
- ✅ Поддержка Twitch и VK Live

## Использование
```
!about username
```

## Примеры ответов
- "🧠 @username: Эмоциональный профиль: радостный (85%). Разговорчивый человек. Любознательный"
- "🧠 @username: Эмоциональный профиль: грустный (72%). Лаконичный в общении"
- "🧠 @username: Эмоциональный профиль: злой (68%). Разговорчивый человек"

## Настройка

### 1. Миграция базы данных
```bash
cd bot_service
alembic upgrade head
```

### 2. Настройка Hugging Face API (обязательно)
1. Зарегистрируйтесь на [Hugging Face](https://huggingface.co/)
2. Получите токен в настройках профиля
3. Замените `hf_your_token_here` в `psychology_service.py` на ваш токен

**Без токена анализ не будет работать!**

### 3. Настройка команды
Команда уже добавлена в базовые команды с настройками:
- **Права доступа**: все пользователи
- **Кулдаун**: 30 секунд
- **Тег**: анализ

## Технические детали

### Алгоритм анализа
1. **Сбор данных**: Получает до 50 последних сообщений за 30 дней
2. **Фильтрация**: Исключает команды (начинающиеся с !)
3. **ИИ анализ**: Отправляет данные в Hugging Face API (анализ эмоций)
4. **Кэширование**: Сохраняет результат на 24 часа

### ИИ анализ
Использует модель для анализа эмоций через Hugging Face API:
- **Модель**: cardiffnlp/twitter-roberta-base-emotion
- **API**: https://api-inference.huggingface.co/
- **Функция**: Анализ эмоций в тексте (радость, грусть, злость, страх, удивление)
- **Результат**: Эмоциональный профиль + дополнительные характеристики

### База данных
- **Таблица**: `psychology_analysis`
- **Индексы**: По дате анализа и пользователям
- **Очистка**: Автоматическая через систему бэкапов

## Ограничения
- Минимум 5 сообщений для анализа
- Максимум 50 сообщений анализируется
- Кулдаун 30 секунд между запросами
- Результат кэшируется на 24 часа

## Безопасность
- Все запросы логируются
- Защита от спама через кулдаун
- Ограничение длины результата (150 символов)
- Валидация входных данных

## Мониторинг
- Логи всех анализов в `bot_service.log`
- Статистика использования в базе данных
- Ошибки API записываются с контекстом
