# Быстрый старт: OAuth авторизация бота

## За 3 минуты до автоматического обновления токена

### 1️⃣ Проверьте что вы админ (10 сек)
```bash
cd bot_service
python scripts/check_admin.py
```

Если нет - сделайте себя админом:
```bash
python scripts/make_admin.py
```

### 2️⃣ Откройте админку (5 сек)
```
http://localhost:5173/settings
```

### 3️⃣ Авторизуйте бота (2 минуты)
1. Найдите карточку **"Управление ботом"** в начале страницы
2. Нажмите **"Авторизовать бота"**
3. Войдите на Twitch **под аккаунтом бота**
4. Подтвердите разрешения
5. Готово! ✅

### 4️⃣ Проверьте статус (10 сек)
```bash
python scripts/check_bot_token.py
```

Должно показать:
```
✅ Токен бота НАСТРОЕН
Логин бота:     yourchy_bot
Осталось:       60 дней
Refresh token:  ✅ Есть (автообновление работает)
```

---

## Что дальше?

**Ничего!** Токен будет обновляться автоматически каждые ~60 дней.

Система проверяет токен:
- При старте сервера
- Каждый час
- При ошибке 401

Если токен истекает < 7 дней → автоматически обновляется.

---

## Альтернатива: TMI Token (30 секунд)

Если нужно **прямо сейчас** запустить бота:

1. Откройте: https://twitchapps.com/tmi/
2. Войдите под аккаунтом бота
3. Скопируйте токен
4. Добавьте в `bot_service/.env`:
   ```bash
   TWITCH_BOT_TOKEN=oauth:ваш_токен
   ```
5. Перезапустите бота

**Минус:** Через 60 дней нужно повторить.

## Troubleshooting

### "Not Found" при авторизации
- Перезапустите backend: `npm run dev:bot`

### "Unauthorized"
- Перелогиньтесь в frontend (удалите cookie `session_id`)

### Карточка не видна
- Проверьте что вы админ: `python scripts/check_admin.py`
- Перелогиньтесь в frontend

### Бот не подключается
- Проверьте логи: `grep "BOT OAUTH" logs/app/*.log`
- Проверьте токен: `python scripts/check_bot_token.py`
