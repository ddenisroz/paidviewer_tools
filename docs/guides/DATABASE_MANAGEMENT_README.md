# 🗄️ Система управления базой данных

## Описание
Автоматическая система очистки и оптимизации базы данных для предотвращения перегрузки и поддержания производительности.

## Настройки лимитов

### 📊 Текущие лимиты:
- **Сообщения на пользователя**: 3,000 записей
- **Сообщения чата всего**: 100,000 записей
- **Психологические анализы**: 1,000 записей  
- **Хранение сообщений**: 90 дней
- **Хранение анализов**: 30 дней

### 🎯 Рекомендуемые лимиты:
- **Для малых каналов** (< 100 зрителей): 1,000 сообщений на пользователя
- **Для средних каналов** (100-1000 зрителей): 3,000 сообщений на пользователя
- **Для больших каналов** (> 1000 зрителей): 5,000 сообщений на пользователя

## Автоматическая очистка

### 📅 Расписание:
- **Ежедневно в 2:00** - Базовая очистка старых данных
- **Воскресенье в 3:00** - Глубокая оптимизация базы данных

### 🔧 Что очищается:
1. **Старые сообщения** (> 90 дней)
2. **Старые анализы** (> 30 дней)
3. **Избыточные записи** (превышение общих лимитов)
4. **Избыточные сообщения пользователей** (превышение лимита 3,000 на пользователя)
5. **Синхронизация счетчиков** (с реальными данными в базе)

## Мониторинг

### 📊 Ключевые метрики:
- **Размер базы данных** (МБ)
- **Количество сообщений** по платформам
- **Количество анализов**
- **Старые записи** для очистки
- **Лимиты на пользователя** (3,000 сообщений)
- **Пользователи с превышением лимита**
- **Счетчики сообщений** для лутбоксов

### ⚠️ Предупреждения:
- База данных приближается к лимиту (> 90%)
- Много старых записей для очистки
- Низкая производительность запросов

## Счетчики сообщений для лутбоксов

### 🎯 Назначение:
Счетчики сообщений используются системой лутбоксов для определения наград и достижений пользователей.

### 📊 Как работает:
1. **При каждом сообщении** увеличивается счетчик `total_messages` в `UserProgression`
2. **Счетчик учитывает все сообщения** (включая удаленные)
3. **Автоматическая синхронизация** каждый день в 2:00
4. **Ручная синхронизация** через API endpoint

### 🔧 Структура данных:
```sql
-- Таблица UserProgression
total_messages INTEGER DEFAULT 0  -- Общее количество сообщений пользователя
```

### ⚡ Производительность:
- **Быстрый доступ** к счетчикам через индексы
- **Batch обновления** при синхронизации
- **Автоматическая очистка** старых записей

### 🛡️ Надежность:
- **Синхронизация с реальными данными** в базе
- **Защита от расхождений** при удалении сообщений
- **Логирование** всех операций синхронизации

## Настройка лимитов

### 🔧 Изменение лимитов:
```python
# В services/database_cleanup_service.py
self.MAX_CHAT_MESSAGES_PER_USER = 5000  # Изменить лимит сообщений на пользователя
self.MAX_TOTAL_CHAT_MESSAGES = 150000  # Изменить общий лимит сообщений
self.CHAT_MESSAGES_RETENTION_DAYS = 60  # Изменить период хранения
```

### 📈 Рекомендации по масштабированию:

#### Для растущих каналов:
1. **Увеличить лимит сообщений** до 100,000
2. **Сократить период хранения** до 60 дней
3. **Добавить архивирование** старых данных

#### Для высоконагруженных систем:
1. **Партиционирование** по датам
2. **Индексы** для быстрого поиска
3. **Кэширование** частых запросов
