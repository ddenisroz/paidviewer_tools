# 🤖 VK Live Bot - Система Команд

## 📋 Обзор

VK Live бот поддерживает полноценную систему команд с проверкой прав пользователей, кулдаунами и модерацией. Бот **автоматически слушается команд** от модераторов и владельцев каналов.

## 👑 Права Доступа

### 🔹 Обычные Пользователи
- Могут использовать информационные команды
- Могут управлять TTS
- **НЕ могут** использовать команды модерации

### 🔸 Модераторы и Владельцы
- Все права обычных пользователей
- **Могут использовать команды модерации** (mute, ban, clear)
- **Полный доступ** ко всем функциям бота

## 📖 Доступные Команды

### 🎤 Команды TTS

#### `!tts [on|off]`
**Описание:** Управление системой озвучки Text-to-Speech  
**Права:** Все пользователи  
**Кулдаун:** 10 секунд  
**Примеры:**
```
!tts on      # Включить TTS
!tts off     # Выключить TTS  
!tts         # Переключить TTS
!tts вкл     # Включить (русская команда)
!tts выкл    # Выключить (русская команда)
```

### 🛡️ Команды Модерации (только модераторы)

#### `!mute @пользователь [минуты]`
**Описание:** Замутить пользователя в чате  
**Права:** Только модераторы  
**Кулдаун:** 5 секунд  
**Примеры:**
```
!mute @BadUser      # Мут на 5 минут (по умолчанию)
!mute @BadUser 10   # Мут на 10 минут
!mute @BadUser 60   # Мут на 1 час
```

#### `!ban @пользователь [причина]`
**Описание:** Забанить пользователя  
**Права:** Только модераторы  
**Кулдаун:** 5 секунд  
**Статус:** ⚠️ Пока не реализовано в VK Live API  
**Примеры:**
```
!ban @BadUser                    # Бан без причины
!ban @BadUser Спам в чате        # Бан с причиной
```

#### `!unban @пользователь`
**Описание:** Разбанить пользователя  
**Права:** Только модераторы  
**Кулдаун:** 5 секунд  
**Статус:** ⚠️ Пока не реализовано в VK Live API  

#### `!clear [количество]`
**Описание:** Очистить чат  
**Права:** Только модераторы  
**Кулдаун:** 30 секунд  
**Статус:** ⚠️ VK Live API не поддерживает удаление сообщений  

### ℹ️ Информационные Команды

#### `!help [команда]`
**Описание:** Показать список команд или справку по команде  
**Права:** Все пользователи  
**Кулдаун:** 30 секунд  
**Примеры:**
```
!help           # Все доступные команды
!help tts       # Справка по команде tts
```

#### `!ping`
**Описание:** Проверить работу бота  
**Права:** Все пользователи  
**Кулдаун:** 5 секунд  
**Ответ:** `🏓 Pong! Бот работает исправно`

#### `!uptime`
**Описание:** Время работы бота и статистика  
**Права:** Все пользователи  
**Кулдаун:** 10 секунд  
**Ответ:** `⏰ Uptime: 2ч 15м 30с | 📨 Сообщений: 142`

## 🔧 Технические Особенности

### 🛡️ Проверка Прав
Бот автоматически определяет права пользователя:
- **`is_owner: true`** - Владелец канала (полные права)
- **`is_moderator: true`** - Модератор (команды модерации)
- **Обычный пользователь** - Базовые команды

### ⏰ Система Кулдаунов
- **Персональные кулдауны** для каждого пользователя
- **Разные интервалы** для разных команд
- **Умное сообщение** о оставшемся времени

### 🚀 Производительность
- **Асинхронная обработка** - команды не блокируют чат
- **Неблокирующие вызовы** - TTS и команды работают параллельно
- **Оптимизированный парсинг** - минимальная задержка

## 🔄 Интеграция с Системой

### Оптимизированный REST API
- Команды обрабатываются с **высоким приоритетом**
- **Не влияют на TTS** - команды не озвучиваются
- **Параллельная обработка** с другими функциями

### TTS Интеграция
- Команды **автоматически исключаются** из TTS
- TTS можно **включать/выключать** командами
- **Мгновенное применение** настроек

### Верификация Гостей
- Команды работают **независимо** от верификации
- **Не блокируют** процесс подключения гостей

## 🛠️ Разработка и Расширение

### Добавление Новых Команд
```python
# В VKLiveCommandHandler.__init__()
self.register_command(
    name="mycmd",
    handler=self._cmd_my_command,
    description="Моя команда",
    usage="!mycmd [параметр]",
    requires_mod=False,  # Доступна всем
    cooldown=10         # 10 секунд кулдаун
)

async def _cmd_my_command(self, channel: str, author: str, author_id: str, args: List[str], message_data: dict):
    await self._send_response(channel, f"@{author} Моя команда работает!")
```

### Настройка Прав
```python
# Изменение требований к правам
command_info['requires_mod'] = True   # Только модераторы
command_info['requires_mod'] = False  # Все пользователи
```

### Кастомные Проверки
```python
# В handle_message можно добавить дополнительные проверки
if command_name == "special" and not some_custom_check(author_id):
    await self._send_response(channel, "Недостаточно прав")
    return
```
