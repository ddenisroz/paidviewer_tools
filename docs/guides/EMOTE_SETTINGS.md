# 🎛️ Настройки озвучки смайликов

## ✅ **Реализованные настройки:**

### 🎭 **7TV смайлы:**
- **Настройка:** "Озвучивать 7TV смайлы"
- **Описание:** Включает/выключает озвучку смайликов из расширения 7TV
- **По умолчанию:** Включено
- **API:** `enable7TV: boolean`

### 🎮 **Twitch смайлы:**
- **Настройка:** "Озвучивать Twitch смайлы"
- **Описание:** Включает/выключает озвучку стандартных Twitch смайликов
- **По умолчанию:** Включено
- **API:** `enableTwitch: boolean`

## 🔧 **Техническая реализация:**

### 📡 **API Endpoints:**
- **`POST /api/tts/settings`** - сохранить настройки
- **`GET /api/tts/settings`** - загрузить настройки

### 💾 **Хранение данных:**
- **Таблица:** `tts_settings`
- **Поле:** `voice_settings` (JSON)
- **Структура:**
```json
{
  "enable7TV": true,
  "enableTwitch": true,
  "enableProfanity": false,
  "profanityLevel": "medium"
}
```

### 🎨 **UI компоненты:**
- **Переключатели:** Switch компоненты
- **Автосохранение:** При изменении настройки
- **Загрузка:** При инициализации страницы

## 🧪 **Тестирование:**

### ✅ **Проверка сохранения:**
1. Переключите настройку
2. Обновите страницу
3. Настройка должна сохраниться

### ✅ **Проверка API:**
```bash
# Получить настройки
GET /api/tts/settings

# Сохранить настройки
POST /api/tts/settings
{
  "enable7TV": false,
  "enableTwitch": true
}
```

## 🚀 **Готово к использованию!**

Обе настройки полностью функциональны и готовы к тестированию.
