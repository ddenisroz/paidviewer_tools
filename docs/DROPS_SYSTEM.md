## Обзор

Система Drops позволяет стримерам создавать систему лутбоксов (сундуков) с различными наградами для зрителей. Система состоит из:

- **Стрики** — зрители получают сундуки за ежедневную активность в чате
- **Донаты** — зрители получают сундуки за донаты (через DonationAlerts)
- **Mythyc drops** — эксклюзивные сундуки за крупные донаты (только для донатов)
- **Items (гача)** — предметы внутри сундуков, которые крутятся как в гача-играх
- **Награды платформы** — награды за баллы через API Twitch/VK

---

## Структура вкладок

На странице `/dashboard/drops` доступны следующие вкладки:

### 1. Стрик
Настройка системы стриков:
- Календарь дней стрика для каждого качества сундука (Common, Rare, Epic, Legendary)
- Количество сообщений в чате для засчета дня
- Опция сброса стрика при пропуске стрима
- Отдельная кнопка для сброса статистики стриков (не затрагивает настройки)

### 2. Донат
Настройка донатных дропсов:
- Минимальные суммы донатов для каждого качества сундука
- Mythyc drops — эксклюзивные сундуки за крупные донаты
- Требуется подключение интеграции DonationAlerts

### 3. Баллы (новая)
Создание наград через API платформы (Twitch/VK):
- Создание, редактирование и удаление наград за баллы канала
- Настройка кулдаунов, лимитов и других параметров платформы
- Управление статусом наград (включено/отключено)

### 4. Награды
Управление items (предметами) внутри сундуков:
- Создание items для каждого качества сундука
- Настройка изображения карточки для гача крутки
- Установка шанса выпадения (weight)
- Название и описание каждого item
- **Важно:** Мифический сундук здесь не настраивается (только для донатов)

### 5. История
Просмотр истории выданных сундуков и наград

### 6. Виджет
Настройка OBS виджета:
- Длительность анимации крутки
- Длительность анимации открытия
- Длительность показа результата
- URL виджета для добавления в OBS
- Предпросмотр анимации в новой вкладке

## Настройка стриков

### Календарь дней стрика
Для каждого качества сундука можно настроить количество дней стрика, которые зритель должен набрать:
- **Обычный (Common)** — по умолчанию 1 день
- **Редкий (Rare)** — по умолчанию 3 дня
- **Эпический (Epic)** — по умолчанию 7 дней
- **Легендарный (Legendary)** — по умолчанию 14 дней

### Дополнительные настройки
- **Сообщений для засчета дня** — количество сообщений в чате за стрим (слайдер от 1 до 100)
- **Сброс при пропуске** — обнулять стрик при неактивности в течение дня

### Сброс статистики
Красная кнопка "Сбросить статистику стриков" удаляет всю статистику стриков зрителей, но не затрагивает настройки системы.

## Настройка донатов

### Минимальные суммы донатов
Для каждого качества сундука устанавливается минимальная сумма доната:
- **Обычный (Common)** — по умолчанию 50₽
- **Редкий (Rare)** — по умолчанию 100₽
- **Эпический (Epic)** — по умолчанию 500₽
- **Легендарный (Legendary)** — по умолчанию 1000₽

### Mythyc Drops
Эксклюзивная система сундуков за крупные донаты:
- **Включить mythyc drops** — переключатель активации
- **Мин. интервал (ч)** — минимальный интервал между появлениями (1-24 часа)
- **Макс. интервал (ч)** — максимальный интервал между появлениями (2-48 часов)
- **Длительность окна (м)** — длительность окна для активации (1-60 минут)
- **Мин. сумма (₽)** — минимальная сумма доната для активации (500-10000₽)

**Важно:** Для использования donation drops необходимо подключить интеграцию DonationAlerts в настройках.

## Управление наградами (items)

На вкладке "Награды" настраиваются items (предметы), которые будут выпадать внутри сундуков при крутке.

### Создание item
Для каждого качества сундука можно создать несколько items:

1. **Название** — название награды (например: "Показать анус на стриме")
2. **Описание** — краткое описание
3. **Качество сундука** — выбор качества (Common, Rare, Epic, Legendary)
4. **Изображение** — картинка для карточки в гача крутке:
   - Можно указать URL изображения
   - Или загрузить файл после создания награды (доступно при редактировании)
5. **Шанс выпадения** — вес награды (от 1 до 1000, чем выше — тем чаще выпадает)

### Принцип работы
- Награда — это крутка сундука определенного качества (как в гача-играх)
- При выпадении зритель увидит анимацию открытия сундука с соответствующим качеством
- Звук и другие эффекты настраиваются в виджете OBS

### Важно
- Мифический сундук не отображается в этой вкладке (только для донатов)
- Без наград система Drops не будет работать

## Управление наградами платформы (баллы)

На вкладке "Баллы" создаются награды через API платформы (Twitch/VK), которые зрители могут покупать за баллы канала.

### Создание награды
1. **Название** — название награды
2. **Описание** — описание награды
3. **Стоимость** — количество баллов
4. **Требуется ввод от пользователя** — зритель должен ввести сообщение при покупке

### Настройки Twitch
- **Глобальный кулдаун** — время восстановления награды (секунды)
- **Макс. использований за стрим** — ограничение на использование (0 = без ограничений)
- **Макс. использований на пользователя за стрим** — ограничение на одного зрителя (0 = без ограничений)
- **Автоматически выполнять** — награда выполняется автоматически без модерации

### Настройки VK Live
- **Таймаут ремонта** — время восстановления награды (секунды)
- **Макс. использований** — общее ограничение (0 = без ограничений)
- **Макс. использований на пользователя** — ограничение на одного зрителя (0 = без ограничений)

### Важно
- Для создания наград требуется подключение интеграции соответствующей платформы
- Награды создаются напрямую через API платформы
- Это отдельная система от items в сундуках

## API Endpoints

### Конфигурация
- `GET /api/drops/config/{channel_name}` — получить конфигурацию
- `PUT /api/drops/config/{channel_name}` — обновить конфигурацию

### Награды (items)
- `GET /api/drops/rewards/{channel_name}` — получить все награды для канала
- `POST /api/drops/rewards/{channel_name}` — создать новую награду (item)
- `PUT /api/drops/rewards/{reward_id}` — обновить награду
- `DELETE /api/drops/rewards/{reward_id}` — удалить награду
- `POST /api/drops/rewards/{reward_id}/image` — загрузить изображение для награды
- `POST /api/drops/rewards/{reward_id}/sound` — загрузить звук для награды

### Стрики
- `POST /api/drops/streak/reset/{channel_name}` — сбросить статистику стриков

### Качества
- `GET /api/drops/qualities` — получить список качеств сундуков

### Награды платформы
- `GET /api/points/platform/rewards` — получить награды платформы
- `POST /api/points/platform/rewards/create` — создать награду на платформе
- `PUT /api/points/platform/rewards/{reward_id}` — обновить награду
- `DELETE /api/points/platform/rewards/{reward_id}` — удалить награду

## База данных

### Таблицы

#### `drops_configs`
Конфигурация Drops для каждого канала:
- Настройки стриков (дни, сообщения, сброс)
- Настройки донатов (минимальные суммы)
- Настройки мифических сундуков
- Настройки виджета (длительности анимаций)

#### `drops_rewards`
Items внутри сундуков:
- `name` — название item
- `description` — описание
- `quality_id` — качество сундука
- `weight` — шанс выпадения
- `image_url` — URL изображения карточки (новое поле)
- `sound_file` — путь к файлу звука
- `sound_volume` — громкость звука
- `is_active` — активен ли item

#### `drops_qualities`
Качества сундуков (Common, Rare, Epic, Legendary)

#### `user_streaks`
Статистика стриков зрителей

#### `drops_history`
История выданных сундуков и наград

#### `mythical_drops_sessions`
Сессии мифических сундуков

## Важные замечания

1. **Мифический сундук** настраивается только в разделе "Донат", не в "Награды"
2. **Donation drops** требуют подключения интеграции DonationAlerts
3. **Items (гача)** — это предметы внутри сундуков, которые крутятся при открытии
4. **Награды платформы** — это отдельные награды за баллы через API
5. **Без items система не работает** — необходимо создать хотя бы один item для каждого качества сундука
