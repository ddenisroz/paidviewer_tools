# 🔑 Как получить и настроить токен Hugging Face

## 📍 **Где брать токен:**

### 1. Регистрация на Hugging Face
1. Идите на [huggingface.co](https://huggingface.co/)
2. Нажмите **"Sign Up"** (справа вверху)
3. Зарегистрируйтесь через:
   - Email
   - GitHub (рекомендуется)
   - Google

### 2. Получение токена
1. После регистрации зайдите в настройки:
   - Нажмите на аватар (справа вверху)
   - Выберите **"Settings"**
2. В левом меню найдите **"Access Tokens"**
3. Нажмите **"New token"**
4. Заполните форму:
   - **Name**: `TTS Bot Analysis` (любое название)
   - **Type**: `Read` (достаточно для анализа)
5. Нажмите **"Generate a token"**
6. **Скопируйте токен** (начинается с `hf_`)

## 📝 **Куда вставлять токен:**

### Вариант 1: В файл .env (рекомендуется)
1. Откройте файл `bot_service/.env`
2. Найдите строку:
   ```
   HUGGINGFACE_API_TOKEN=your_huggingface_token_here
   ```
3. Замените на ваш токен:
   ```
   HUGGINGFACE_API_TOKEN=hf_your_real_token_here
   ```

### Вариант 2: Если нет файла .env
1. Скопируйте `bot_service/env.example` в `bot_service/.env`
2. Откройте `bot_service/.env`
3. Найдите строку с `HUGGINGFACE_API_TOKEN`
4. Вставьте ваш токен

## 🔧 **Пример настройки:**

```bash
# В файле bot_service/.env
HUGGINGFACE_API_TOKEN=hf_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

## ✅ **Проверка работы:**

После настройки токена:
1. Перезапустите бота
2. В чате напишите: `!about username`
3. Должен появиться анализ эмоций

## ❌ **Если не работает:**

### Ошибка 401 (Unauthorized):
- Проверьте правильность токена
- Убедитесь, что токен начинается с `hf_`
- Проверьте права токена (должны быть "Read")

### Ошибка 429 (Too Many Requests):
- Превышен лимит запросов (1000/месяц бесплатно)
- Подождите или купите платный план

### Ошибка 503 (Service Unavailable):
- Модель загружается (первый запрос может занять время)
- Попробуйте через несколько минут

## 💰 **Лимиты Hugging Face:**

- **Бесплатно**: 1000 запросов в месяц
- **Pro**: $9/месяц - 10,000 запросов
- **Enterprise**: $20/месяц - 50,000 запросов

## 🔒 **Безопасность:**

- **Не делитесь токеном** с другими
- **Не публикуйте** токен в открытом доступе
- **Используйте переменные окружения** (.env файл)
- **Регулярно обновляйте** токен
