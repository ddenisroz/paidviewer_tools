# 🤖 Настройка ИИ для анализа личности

## Что такое Hugging Face?

**Hugging Face** - это платформа с открытыми моделями ИИ. У них есть **Inference API** - это готовый сервис для использования моделей без установки на свой сервер.

## Как получить токен:

### 1. Регистрация
1. Идите на [huggingface.co](https://huggingface.co/)
2. Нажмите "Sign Up"
3. Зарегистрируйтесь (можно через GitHub)

### 2. Получение токена
1. Зайдите в настройки профиля
2. Перейдите в раздел "Access Tokens"
3. Нажмите "New token"
4. Выберите "Read" права
5. Скопируйте токен (начинается с `hf_`)

### 3. Настройка в коде
Замените в файле `bot_service/services/psychology_service.py`:

```python
# Было:
"Authorization": "Bearer hf_your_token_here"

# Стало:
"Authorization": "Bearer hf_your_real_token_here"
```

## Какая модель используется?

**cardiffnlp/twitter-roberta-base-emotion** - модель для анализа эмоций в тексте.

**Что анализирует:**
- Радость (joy)
- Грусть (sadness) 
- Злость (anger)
- Страх (fear)
- Удивление (surprise)
- Раздражение (disgust)

**Как работает:**
1. Анализирует эмоции в сообщениях пользователя
2. Определяет доминирующую эмоцию с процентом уверенности
3. Добавляет дополнительные характеристики (разговорчивость, любознательность)
4. Возвращает результат на русском языке

## Лимиты Hugging Face:

- **Бесплатно**: 1000 запросов в месяц
- **Платно**: От $9/месяц за больше запросов

## Альтернативы:

Если Hugging Face не подходит, можно использовать:
- **OpenAI API** (платно)
- **Anthropic Claude** (платно)
- **Локальная модель** (сложно)

## Проверка работы:

После настройки токена команда `!about username` должна работать и возвращать анализ личности на русском языке.
