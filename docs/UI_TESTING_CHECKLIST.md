## 🐛 Известные проблемы

### Если обнаружены проблемы:

1. **Медленная загрузка**
   - Проверить размер бандла
   - Проверить количество запросов
   - Проверить использование React Query кэша

2. **WebSocket проблемы**
   - Проверить логи переподключения
   - Проверить обработку ошибок соединения
   - Проверить очистку подписок

3. **Синхронизация**
   - Проверить инвалидацию кэша React Query
   - Проверить обработку конфликтов (409)
   - Проверить оптимистичные обновления

4. **Не работающие кнопки**
   - Проверить обработчики событий
   - Проверить состояние загрузки
   - Проверить права доступа
