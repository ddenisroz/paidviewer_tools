# 🎨 Исправление UI QuickActionsBar
**Дата:** 6 ноября 2025  
**Статус:** ✅ Завершено

---

## 🐛 Проблемы

### До исправления:
1. ❌ **Кнопка "Стрик" - желтый цвет**
   - Используется `yellow-600` вместо `orange-600`
   - Не соответствует огненной тематике стрика
   
2. ❌ **Перенос текста**
   - Слово "Стрик" переносится на две строки
   - Текст "ВКЛ/ВЫКЛ" тоже переносится
   - Выглядит ужасно на маленьких экранах

3. ❌ **Несогласованность**
   - Все кнопки используют "ВКЛ/ВЫКЛ" по-русски
   - Не хватает места для текста

---

## ✅ Исправления

### 1. Цвет стрика: Yellow → Orange

**До:**
```jsx
className={`... ${
    streakEnabled
        ? 'bg-gradient-to-r from-yellow-600 to-yellow-500 hover:from-yellow-700 hover:to-yellow-600 text-white shadow-lg shadow-yellow-600/40'
        : '...'
}`}
```

**После:**
```jsx
className={`... ${
    streakEnabled
        ? 'bg-gradient-to-r from-orange-600 to-orange-500 hover:from-orange-700 hover:to-orange-600 text-white shadow-lg shadow-orange-600/40'
        : '...'
}`}
```

**Результат:** 🔥 Огненный оранжевый цвет как в игровых стриках

---

### 2. Предотвращение переноса текста

**Добавлено для ВСЕХ кнопок:**
- `whitespace-nowrap` - запрет переноса
- `gap-1.5` вместо `gap-2` - уменьшен отступ
- `px-3` вместо `px-4` - уменьшен padding
- `flex-shrink-0` для иконок и бейджей
- `truncate` для текста (на всякий случай)

**До:**
```jsx
<button className="w-40 h-10 flex items-center justify-center gap-2 px-4 ...">
    <Zap className="w-4 h-4" />
    <span>Стрик</span>
    <span className="text-xs ...">
        {streakEnabled ? 'ВКЛ' : 'ВЫКЛ'}
    </span>
</button>
```

**После:**
```jsx
<button className="w-40 h-10 flex items-center justify-center gap-1.5 px-3 ... whitespace-nowrap">
    <Zap className="w-4 h-4 flex-shrink-0" />
    <span className="truncate">Стрик</span>
    <span className="text-[10px] ... flex-shrink-0">
        {streakEnabled ? 'ON' : 'OFF'}
    </span>
</button>
```

---

### 3. ВКЛ/ВЫКЛ → ON/OFF

**Причины:**
- ✅ Короче (2-3 символа вместо 3-4)
- ✅ Универсально понятно
- ✅ Выглядит более технично
- ✅ Не переносится на маленьких экранах

**Изменения:**
- `text-xs` → `text-[10px]` (меньше размер для ON/OFF)
- `px-2` → `px-1.5` (меньше padding)

## 🔧 Технические детали

### Layout оптимизация:
```jsx
// Контейнер кнопки
className="w-40 h-10"           // фиксированный размер
         "flex items-center"     // вертикальное центрирование
         "justify-center"        // горизонтальное центрирование
         "gap-1.5"               // минимальный отступ (6px)
         "px-3"                  // padding по горизонтали (12px)
         "whitespace-nowrap"     // ЗАПРЕТ переноса

// Иконка
className="w-4 h-4 flex-shrink-0"  // не сжимается

// Текст
className="truncate"               // обрезается если не влезает

// Бейдж ON/OFF
className="text-[10px]"            // кастомный размер 10px
         "px-1.5 py-0.5"           // минимальный padding
         "flex-shrink-0"           // не сжимается
```
