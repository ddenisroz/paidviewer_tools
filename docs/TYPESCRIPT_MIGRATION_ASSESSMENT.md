## 💡 Что упростит миграцию

### 1. Использовать `allowJs: true`
```json
{
  "compilerOptions": {
    "allowJs": true,  // Позволяет смешивать JS и TS
    "checkJs": true   // Проверяет JS файлы
  }
}
```

**Преимущества:**
- Можно мигрировать постепенно
- Старый код продолжает работать
- Нет необходимости мигрировать все сразу

### 2. Начать с простых файлов
**Приоритет миграции:**
1. Service Layer (самый простой)
2. Утилиты и хелперы
3. React Query hooks
4. Компоненты (по приоритету использования)
5. Контексты (в конце)

### 3. Использовать существующие типы
- `@types/react` - уже установлен
- `@types/react-dom` - нужно установить
- `@types/node` - для Node.js API
- Типы из библиотек (axios, react-query)

### 4. Создать типы для API заранее
```typescript
// types/api.d.ts
export interface ApiResponse<T> {
  success: boolean;
  data: T;
  error?: string;
}
```
