## ✏️ ШАГ 5: ВНЕСЕНИЕ ИЗМЕНЕНИЙ (5 мин)

### Правила:

- [ ] Использую `search_replace` для **ТОЧЕЧНЫХ** изменений
- [ ] НЕ переписываю большие блоки кода
- [ ] НЕ "улучшаю" работающий код
- [ ] Добавляю логирование если нужно
- [ ] Сохраняю существующий стиль кода

### Пример ПРАВИЛЬНОГО изменения:

```python
# ✅ ХОРОШО: Точечное исправление
search_replace(
    file_path="api/feature.py",
    old_string="if value == None:",  # Нашли точный баг
    new_string="if value is None:"   # Исправили только это
)
```

### Пример НЕПРАВИЛЬНОГО изменения:

```python
# ❌ ПЛОХО: Переписывание всей функции
search_replace(
    file_path="api/feature.py",
    old_string="""def working_function():
        # 50 строк рабочего кода
    """,
    new_string="""def working_function():
        # Переписал всё "лучше" - сломал всё
    """
)
```
