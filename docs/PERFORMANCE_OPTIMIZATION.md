# Оптимизация производительности фронтенда

## Проблема: Видимая отрисовка при загрузке страницы

### Основные причины:

1. **Анимации при загрузке** (`usePageAnimation`) - создают видимый эффект "появления" элементов
2. **Много синхронных провайдеров** - замедляют первый рендер
3. **React Query запросы после монтирования** - нет начального состояния, видна пустая страница
4. **Отсутствие skeleton states** - видна пустая страница вместо placeholder'ов
5. **CSS загружается асинхронно** - возможен FOUT (Flash of Unstyled Text)

### Отличия от Pointauc:

1. **Redux Toolkit** - предзагруженное состояние, нет видимых запросов
2. **SSR/Static Generation** - критические данные уже в HTML
3. **Нет видимых анимаций** при загрузке - используется оптимистичный UI
4. **CSS Modules** - стили инлайнятся или загружаются синхронно

### Решения:

1. ✅ Убрать `usePageAnimation` или сделать его невидимым
2. ✅ Добавить skeleton states для критичных компонентов
3. ✅ Lazy load провайдеров где возможно
4. ✅ Prefetch критичных данных
5. ✅ Использовать critical CSS inline
