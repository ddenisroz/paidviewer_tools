# 🏗️ TTS_rus_engine - Техническая документация для агента

## 📋 Обзор системы

**TTS_rus_engine** - это высокопроизводительная система синтеза речи на основе F5-TTS с поддержкой русского и английского языков. Система обеспечивает zero-shot voice cloning с референсного аудио и автоматическую обработку текста.

## 🎯 Основные возможности

- **Zero-shot voice cloning** - клонирование голоса с одного референсного аудио
- **Мультиязычная поддержка** - русский и английский языки
- **Автоматическая обработка** - ударения, ёфикация, определение параметров
- **CUDA ускорение** - быстрый синтез на GPU
- **Веб-интерфейс** - удобный интерфейс с настройкой скорости
- **Высокое качество** - естественная и выразительная речь

### Движок синтеза речи: F5-TTS

**F5-TTS (Flow Matching for Text-to-Speech)** - современная нейросетевая архитектура для синтеза речи, основанная на flow matching.

**Ключевые особенности:**
- **Flow Matching** - генеративная модель, превосходящая диффузионные модели
- **Zero-shot voice cloning** - клонирование голоса с одного референсного аудио
- **Мультиязычная поддержка** - русский и английский языки
- **Высокое качество** - естественная и выразительная речь

def detect_language(text):
    # Подсчет кириллических и латинских символов
    cyrillic_count = len(re.findall(r'[а-яё]', text, re.IGNORECASE))
    latin_count = len(re.findall(r'[a-z]', text, re.IGNORECASE))
    
    if cyrillic_count > latin_count:
        return "russian"
    else:
        return "english"

## 🎛️ Настройки синтеза

### Доступные параметры
- **speed** (0.1-2.0) - скорость произношения

- Скорость зависит от длины текста

## 🔧 API для агента

### Основной класс: RussianTTS

```python
from russian_tts import RussianTTS

# Инициализация
tts = RussianTTS(
    enable_accent=True,           # Включить ударения
    accent_model_size="turbo",    # Размер модели ударений
    ode_method="euler",           # Метод ODE
    use_ema=True                  # Использовать EMA
)

# Синтез речи
audio_path = tts.synthesize_speech(
    text="Привет! Как дела?",
    ref_audio_path="path/to/reference.wav",
    ref_text="Текст для референсного голоса"
)
```

### Методы класса

#### `synthesize_speech(text, ref_audio_path, ref_text, **kwargs)`
Синтезирует речь из текста.

**Параметры:**
- `text` (str) - текст для синтеза
- `ref_audio_path` (str) - путь к референсному аудио
- `ref_text` (str) - текст референсного аудио
- `speed` (float, optional) - скорость речи (0.1-2.0)
- `nfe_step` (int, optional) - количество итераций (10-50)
- `target_rms` (float, optional) - громкость (0.01-1.0)
- `sway_sampling_coef` (float, optional) - случайность (-2.0-2.0)
- `cfg_strength` (float, optional) - сила guidance (0.5-5.0)
- `silence_duration_ms` (int, optional) - тишина в конце (0-2000)

**Возвращает:**
- `str` - путь к созданному аудиофайлу

#### `preprocess_text_for_tts(text)`
Предобрабатывает текст для синтеза.

**Параметры:**
- `text` (str) - исходный текст

**Возвращает:**
- `str` - обработанный текст с ударениями и ёфикацией

#### `detect_language(text)`
Определяет язык текста.

**Параметры:**
- `text` (str) - текст для анализа

**Возвращает:**
- `str` - "russian" или "english"

#### `add_accents(text)`
Добавляет ударения к русскому тексту.

**Параметры:**
- `text` (str) - русский текст

**Возвращает:**
- `str` - текст с ударениями

## 🐛 Обработка ошибок

### Типичные ошибки
1. **CUDA недоступна** - система автоматически переключится на CPU
2. **Недостаточно памяти** - уменьшите длину текста или используйте CPU
3. **Модель не загружена** - проверьте подключение к интернету
4. **Неправильный формат аудио** - используйте WAV, MP3, FLAC

### Логирование
Все операции логируются с уровнем INFO. Для отладки можно изменить уровень:

```python
import logging
logging.basicConfig(level=logging.DEBUG)
```
