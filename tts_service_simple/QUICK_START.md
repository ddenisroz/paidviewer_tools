# ⚡ Быстрый старт - Локальный TTS за 3 минуты

## 🎯 Что это?

Локальный F5-TTS сервис, который запускается на вашем компьютере и предоставляет голосовую озвучку для бота **БЕЗ** облака.

---

## 🚀 Установка (3 шага)

### Шаг 1: Откройте терминал в папке `tts_service_simple`

```bash
cd tts_service_simple
```

### Шаг 2: Установите зависимости

```bash
python install.py
```

*Установка займёт ~2-3 минуты*

### Шаг 3: Запустите сервис

**Windows:**
```batch
start.bat
```

**Linux/Mac:**
```bash
chmod +x start.sh
./start.sh
```

---

## ✅ Проверка

Откройте браузер: http://localhost:8001

Вы должны увидеть:
```json
{
  "message": "TTS F5 Simple - Упрощенный микросервис...",
  "version": "1.0.0",
  "status": "running"
}
```

**✅ Работает!**

## 🔗 Подключение к боту

### 1. Найдите API ключ

Откройте файл `config.json` и скопируйте значение `api_key`:

```json
{
  "api_key": "ваш-длинный-ключ-здесь",
  ...
}
```

### 2. Откройте бот

Перейдите: **Dashboard → TTS → Локальный движок**

### 3. Введите данные

- **URL**: `http://localhost:8001`
- **API Key**: *вставьте скопированный ключ*

### 4. Тест и сохранение

1. Нажмите **"Тест соединения"** ✅
2. Нажмите **"Сохранить"** 💾
3. Нажмите **"Включить"** 🟢

## ❓ Проблемы?

### Сервис не запускается
```bash
# Проверьте порт
netstat -ano | findstr 8001  # Windows
lsof -i :8001                # Linux/Mac
```

### Нет GPU
Сервис работает и без GPU (медленнее). Установите драйверы NVIDIA для ускорения.

### Бот не подключается
1. Убедитесь что сервис запущен: http://localhost:8001/health
2. Проверьте API ключ в `config.json`
3. Перезапустите сервис
