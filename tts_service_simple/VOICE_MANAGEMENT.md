# 🎤 Управление голосами - Руководство

**Локальный TTS сервис** поддерживает загрузку и клонирование пользовательских голосов.

---

## 📁 Структура директорий

```
tts_service_simple/
├── user_voices/          # Пользовательские голоса
│   ├── custom_abc123/    # Папка голоса (ID)
│   │   ├── metadata.json # Метаданные голоса
│   │   ├── samples.json  # Метаданные сэмплов
│   │   ├── sample_1.wav  # Референсные аудио
│   │   ├── sample_2.wav
│   │   └── sample_3.wav
│   └── custom_def456/
│       └── ...
├── reference_audio/      # Общие референсные аудио
└── models/               # Модели F5-TTS
```

## 🔌 API Endpoints

### 1. Получить список голосов

```http
GET /api/voices/list
```

**Ответ:**
```json
{
  "success": true,
  "voices": [
    {
      "id": "female_1",
      "name": "Женский 1",
      "type": "base",
      "language": "ru"
    },
    {
      "id": "custom_abc123",
      "name": "Мой голос",
      "type": "custom",
      "language": "ru",
      "created_at": "2025-10-27T12:00:00",
      "samples_count": 3
    }
  ]
}
```

### 2. Создать новый голос

```http
POST /api/voices/create
Content-Type: multipart/form-data

name: "Мой голос"
language: "ru"
description: "Описание голоса"
```

**Ответ:**
```json
{
  "success": true,
  "voice_id": "custom_abc123",
  "message": "Голос создан. Теперь загрузите референсные аудио сэмплы."
}
```

### 3. Загрузить сэмпл для голоса

```http
POST /api/voices/{voice_id}/upload
Content-Type: multipart/form-data

file: [audio file]
sample_text: "Текст, произносимый в аудио" (опционально)
```

**Поддерживаемые форматы:** WAV, MP3, FLAC

**Ответ:**
```json
{
  "success": true,
  "filename": "sample_1698412800.wav",
  "message": "Сэмпл успешно загружен"
}
```

### 4. Получить сэмплы голоса

```http
GET /api/voices/{voice_id}/samples
```

**Ответ:**
```json
{
  "success": true,
  "samples": [
    {
      "filename": "sample_1.wav",
      "path": "/api/voices/custom_abc123/samples/sample_1.wav",
      "text": "Пример текста",
      "uploaded_at": "2025-10-27T12:00:00",
      "size": 524288
    }
  ]
}
```

### 5. Получить файл сэмпла

```http
GET /api/voices/{voice_id}/samples/{filename}
```

Возвращает аудио файл.

### 6. Удалить сэмпл

```http
DELETE /api/voices/{voice_id}/samples/{filename}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Сэмпл удалён"
}
```

### 7. Удалить голос

```http
DELETE /api/voices/{voice_id}
```

Удаляет голос со всеми сэмплами.

**Ответ:**
```json
{
  "success": true,
  "message": "Голос удалён"
}
```

## 🎯 Рекомендации по сэмплам

### Качество аудио

- **Формат:** WAV 16-bit, 48000 Hz (рекомендуется)
- **Длительность:** 3-10 секунд на сэмпл
- **Количество:** Минимум 3 сэмпла, рекомендуется 5-10
- **Тишина:** Избегайте фонового шума
- **Эмоции:** Используйте нейтральную интонацию

### Что записывать

- ✅ Чистая речь без музыки
- ✅ Нормальная громкость
- ✅ Разные фразы (не повторяющиеся)
- ✅ Естественная интонация
- ❌ Крики, шёпот
- ❌ Фоновый шум, музыка
- ❌ Эхо, реверберация

### Пример текстов для записи

```
1. "Привет! Меня зовут [имя], и я рад приветствовать вас."
2. "Сегодня прекрасная погода для прогулки по парку."
3. "Спасибо за внимание, увидимся на следующем стриме!"
4. "Добро пожаловать на мой канал, подписывайтесь!"
5. "Это тестовое сообщение для клонирования голоса."
```

## 🐛 Устранение проблем

### Проблема: "Голос не найден"
**Решение:** Проверьте, что папка `user_voices/{voice_id}` существует.

### Проблема: "Неподдерживаемый формат"
**Решение:** Используйте только WAV, MP3, или FLAC.

### Проблема: "Плохое качество клонирования"
**Решение:** 
- Добавьте больше сэмплов (минимум 5)
- Улучшите качество записи
- Удалите шумные сэмплы
