# Product Overview

TTS_TTV_0.02 is a production-ready Text-to-Speech bot for Twitch and VK Live streamers. It provides cloud-based (Google TTS) and local (F5-TTS) speech synthesis with comprehensive streaming platform integrations.

## Core Features

- **Multi-platform TTS**: Google Cloud TTS and local F5-TTS synthesis
- **Streaming platforms**: Full Twitch and VK Live integration with OAuth, chat, commands, and badges
- **Media management**: YouTube queue system with player controls
- **Engagement systems**: Channel points, drops/lootbox, streak rewards, and DonationAlerts integration
- **Guest mode**: View chat without authentication
- **OBS widgets**: Chat, TTS, YouTube, and Drops overlays
- **Admin panel**: User and voice management

## Target Users

Streamers on Twitch and VK Live who want to add interactive TTS functionality to their streams with comprehensive engagement features.
