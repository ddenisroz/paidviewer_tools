# Настройка VK Live "бота" для гостевого режима

## Обзор

VK Live не имеет отдельной системы ботов как Twitch. Для гостевого режима мы используем обычный пользовательский аккаунт VK Live, который подключается к каналам и выполняет верификацию пользователей через специальный код.

## Шаги настройки

### 1. Создание специального аккаунта для "бота"

1. Создайте отдельный аккаунт VK для использования в качестве "бота"
2. Или используйте существующий аккаунт администратора
3. Убедитесь, что у аккаунта есть доступ к VK Live

### 2. Получение пользовательского токена

1. Перейдите в [VK Live Developer Console](https://dev.live.vkvideo.ru/)
2. Войдите в аккаунт, который будет использоваться как "бот"
3. Создайте новое приложение:
   - Нажмите "Создать приложение"
   - Выберите тип "Веб-приложение"
   - Заполните название и описание
   - Сохраните приложение
4. Получите токен доступа через OAuth:
   - Используйте scope: `channel:stream:settings`
   - Получите access_token для этого аккаунта

### 3. Настройка переменных окружения

Добавьте в файл `.env`:

```env
# VK Live User Token для гостевого режима (обычный пользовательский токен)
VK_LIVE_USER_TOKEN=your_vk_live_user_access_token_here
```

### 4. Настройка прав бота

Убедитесь, что токен имеет следующие права:
- `channel:stream:settings` - для управления настройками стрима

### 5. Тестирование

После настройки вы можете протестировать бота:

1. Запустите сервер: `python bot_service/main.py`
2. Отправьте POST запрос на `/api/chat/vk/guest/connect` с параметром `channel_name`
3. Получите код верификации
4. Отправьте этот код в чат VK Live канала
5. Бот должен подтвердить верификацию

## API Эндпоинты

### Подключение к каналу
```
POST /api/chat/vk/guest/connect
{
  "channel_name": "your_channel_name"
}
```

### Отключение от канала
```
POST /api/chat/vk/guest/disconnect
{
  "channel_name": "your_channel_name"
}
```

### Проверка статуса
```
GET /api/chat/vk/guest/status?channel_name=your_channel_name
```

## Безопасность

- Коды верификации генерируются случайно и имеют ограниченное время жизни
- Каждый канал может иметь только одну активную верификацию
- Верификация сохраняется в базе данных для отслеживания

## Логирование

Все действия бота логируются в `bot_service/logs/bot_service.log` с префиксом `vk_live_bot`.

## Устранение неполадок

### Бот не подключается к каналу
- Проверьте правильность токена бота
- Убедитесь, что бот имеет необходимые права
- Проверьте, что канал существует и доступен

### Верификация не работает
- Убедитесь, что код верификации отправлен точно как показано
- Проверьте, что бот может читать сообщения в чате
- Проверьте логи на наличие ошибок

### Ошибки в логах
- Проверьте подключение к интернету
- Убедитесь, что VK Live API доступен
- Проверьте правильность конфигурации
