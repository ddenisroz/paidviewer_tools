## 🚀 Быстрый запуск

### 1️⃣ Настройка (единоразово)
```bash
# Скопируйте и заполните конфиг
copy test.env.example .env
# Отредактируйте .env - укажите ваши Twitch токены
```

### 2️⃣ Запуск
```bash
# Просто запустите!
start_microservices.bat
```

## 🔍 Проверка работоспособности

После запуска проверьте:

1. **TTS Health**: http://localhost:8001/health
   - Должно показать `"tts_ready": true`
   - В логах: `"Загружен референсный текст из speaker1.txt"`

2. **Bot Health**: http://localhost:8000/health  
   - Должно показать статус подключения к Twitch

3. **Frontend**: http://localhost:5173
   - Интерфейс управления ботом

## 🛠️ Альтернативный запуск (ручной)

Если batch файл не работает:

```bash
# Терминал 1: TTS
cd tts-service
python main.py

# Терминал 2: Bot  
cd bot-service
python main.py

# Терминал 3: Frontend
cd frontend
npm run dev
```

- `!unmute` - Включить TTS
- `!test` - Проверка бота
