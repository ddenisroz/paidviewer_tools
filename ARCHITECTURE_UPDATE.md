# ✅ ОБНОВЛЕННАЯ АРХИТЕКТУРА - ДИНАМИЧЕСКОЕ ПОДКЛЮЧЕНИЕ

## 🎯 **Новая логика работы:**

### **1. Авторизация через дашборд:**
- Стример заходит в дашборд
- Авторизуется через Twitch OAuth
- Выбирает свой канал
- Бот автоматически подключается к выбранному каналу

### **2. Управление через дашборд:**
- Включение/выключение TTS
- Настройка команд
- Модерация чата
- Все настройки сохраняются в куки

### **3. Работа до разлогинивания:**
- Бот работает пока стример не разлогинится
- Настройки сохраняются в куки
- При повторном входе - настройки восстанавливаются

## 🔧 **Что изменилось:**

### **ENV файл:**
```env
# УБРАНО:
TWITCH_CHANNELS=your_channel_name

# ДОБАВЛЕНО:
TWITCH_CLIENT_ID=your_twitch_client_id
TWITCH_CLIENT_SECRET=your_twitch_client_secret
# Примечание: каналы подключаются динамически через дашборд
```

### **Bot API:**
```python
# Новые endpoints:
POST /api/bot/connect?channel=username&user_id=123
POST /api/bot/disconnect?user_id=123
GET /api/bot/status/{user_id}
```

### **Bot класс:**
```python
class Bot:
    def __init__(self):
        self.connected_channels = set()      # Подключенные каналы
        self.user_settings = {}             # Настройки пользователей
        # Каналы подключаются динамически
```

## 🚀 **Поток работы:**

### **1. Стример заходит в дашборд:**
```
1. Открывает дашборд
2. Нажимает "Войти через Twitch"
3. Авторизуется через OAuth
4. Выбирает свой канал
5. POST /api/bot/connect?channel=username&user_id=123
6. Бот подключается к каналу
```

### **2. Настройка через дашборд:**
```
1. Включает/выключает TTS
2. Настраивает команды
3. Управляет модерацией
4. Настройки сохраняются в куки
```

### **3. Работа бота:**
```
1. Слушает чат канала
2. Озвучивает сообщения (если TTS включен)
3. Отвечает на команды
4. Модерирует чат
```

### **4. Разлогинивание:**
```
1. Стример выходит из дашборда
2. POST /api/bot/disconnect?user_id=123
3. Бот отключается от канала
4. Настройки остаются в куки
```
