# 🚀 Quick Start Testing

## 5-Минутная подготовка

### 1️⃣ Запустить Backend
```bash
cd bot_service
python main.py
# Должны увидеть:
# ✓ === BOT SERVICE STARTED ===
# ✓ Uvicorn running on http://127.0.0.1:8000
```

### 2️⃣ Запустить Frontend
```bash
cd frontend
npm run dev
# Должны увидеть:
# ✓ Local:   http://localhost:5173
```

### 3️⃣ Залогиниться как админ
- Перейти на http://localhost:5173
- Залогиниться (использовать тестовый аккаунт с `is_admin=True`)
- Перейти на `/dashboard/admin`

## 🧪 Быстрое тестирование (10 минут на каждый таб)

### Таб 1: Хранилище (Storage Management)
```
⏱️ Время: ~10 минут

1. ✅ Проверить загрузку
   - Видна ли общая статистика?
   - Отображается ли индикатор здоровья?

2. ✅ Тестировать очистку
   - Нажать "Очистить логи"
   - Дождаться toast с успехом
   - Проверить что logs_size_bytes уменьшился

3. ✅ Тестировать backup
   - Нажать "Создать резервную копию"
   - Проверить что дата обновилась

4. ✅ Error handling
   - Проверить что при ошибке показывается toast
```

### Таб 2: Логи (System Logs)
```
⏱️ Время: ~10 минут

1. ✅ Проверить загрузку
   - Видны ли логи действий?
   - Отображается ли статистика?

2. ✅ Тестировать фильтры
   - Поменять период (1, 7, 30, 90 дней)
   - Выбрать тип действия
   - Выбрать статус (Успешно/Ошибка)
   - Проверить что логи обновляются

3. ✅ Тестировать пагинацию
   - Нажать "Вперед" / "Назад"
   - Проверить что кнопки отключаются на краях
```

### Таб 3: Боты (Bot Management)
```
⏱️ Время: ~10 минут

1. ✅ Проверить загрузку
   - Все карточки видны? (TTS, WebSocket, Платформы, Система)
   - Данные заполнены?

2. ✅ Проверить auto-refresh
   - Откройте страницу
   - Наблюдайте за обновлением каждые 10 секунд
   - Проверьте что нет утечки памяти (DevTools > Performance)

3. ✅ Проверить токены
   - Видны ли даты истечения токенов?
   - Цвет правильный (зелёный/жёлтый)?
```

### Таб 4: Ошибки (Error Logs)
```
⏱️ Время: ~10 минут

1. ✅ Проверить загрузку
   - Видны ли логи?
   - Цвета правильные (красный/жёлтый/синий)?

2. ✅ Тестировать фильтры
   - Выбрать "Ошибки (ERROR)"
   - Выбрать "Предупреждения (WARNING)"
   - Выбрать "Информация (INFO)"
   - Выбрать разное количество строк (50/100/200/500)

3. ✅ Проверить статистику
   - Видны ли карточки со статистикой?
   - Цифры обновляются при фильтрации?
```

## 📋 Чек-лист баагов

Если что-то не работает:
- [ ] Видна ли ошибка в console (F12)?
- [ ] Видна ли ошибка в Network tab?
- [ ] Есть ли ошибка на backend (смотреть логи)?
- [ ] Проверить что данные есть в БД?
