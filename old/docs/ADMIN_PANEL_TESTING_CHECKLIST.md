## 📦 Storage Management

### Функциональность
- Просмотр статистики БД (размер, количество записей)
- Очистка логов старше 30 дней
- Очистка неиспользуемых голосов
- Очистка кеша
- Создание резервной копии
- Восстановление из резервной копии

### Чек-лист

#### ✅ Загрузка данных
- [ ] Страница загружается без ошибок
- [ ] Отображается общая статистика (размер БД, записей)
- [ ] Индикатор здоровья показывает статус (✅ Здорово / ⚠️ Требует внимания / 🚨 Критично)
- [ ] Все значения обновляются при нажатии "Обновить"

#### ✅ Очистка логов
- [ ] Кнопка "Очистить логи > 30 дней" видна
- [ ] Клик на кнопку запускает loading
- [ ] Появляется toast "✅ logs очищен успешно"
- [ ] Статистика обновляется после очистки
- [ ] logs_size_bytes уменьшается

#### ✅ Очистка голосов
- [ ] Кнопка "Очистить неиспользуемые" видна
- [ ] После клика запускается операция
- [ ] Toast показывает результат
- [ ] voices_size_bytes уменьшается (если были неиспользуемые)
- [ ] voices_count обновляется

#### ✅ Очистка кеша
- [ ] Кнопка "Очистить весь кеш" видна
- [ ] Операция завершается без ошибок
- [ ] cache_size_bytes становится 0 или меньше
- [ ] cache_files обновляется

#### ✅ Резервная копия
- [ ] Кнопка "Создать резервную копию" работает
- [ ] После успеха показывается toast
- [ ] Дата последнего бэкапа обновляется
- [ ] Размер бэкапа отображается корректно

#### ✅ Восстановление
- [ ] Кнопка "Восстановить из бэкапа" доступна (если есть бэкап)
- [ ] После клика появляется подтверждение (если есть)
- [ ] Операция завершается успешно
- [ ] Toast показывает результат

#### ❌ Error Cases
- [ ] При ошибке операции появляется toast с ошибкой
- [ ] Keine обновления UI при ошибке
- [ ] Loading отменяется при ошибке

## 📋 System Logs

### Функциональность
- Просмотр логов действий администраторов
- Фильтрация по типу действия, админу, пользователю, статусу
- Фильтрация по дате (1-90 дней)
- Пагинация логов
- Статистика по действиям и администраторам

### Чек-лист

#### ✅ Загрузка данных
- [ ] Страница загружается без ошибок
- [ ] Отображается статистика (всего действий, типов, админов)
- [ ] Таблица логов заполняется данными (если есть логи)
- [ ] Пустая страница показывает "Нет логов" (если логов нет)

#### ✅ Фильтры
- [ ] Dropdown "Период" работает (1, 7, 30, 90 дней)
- [ ] При смене периода логи обновляются
- [ ] Dropdown "Тип действия" заполняется правильно
- [ ] Фильтр по типу действия работает
- [ ] Dropdown "Статус" работает (Все, Успешно, Ошибка, Предупреждение)

#### ✅ Таблица логов
- [ ] Каждый лог отображает:
  - ✅ Статус (иконка + цвет)
  - ✅ Описание действия
  - ✅ Имя админа
  - ✅ Целевого пользователя (если применимо)
  - ✅ Дату и время
  - ✅ Сообщение об ошибке (если ошибка)
- [ ] Клик на "Обновить" перезагружает логи
- [ ] Цвета логов соответствуют статусу

#### ✅ Пагинация
- [ ] Кнопка "Назад" отключена на первой странице
- [ ] Кнопка "Вперед" отключена на последней странице
- [ ] Отображается номер текущей страницы
- [ ] Переход на другую страницу работает

#### ✅ Топ администраторов
- [ ] Карточка "Топ администраторов" отображается
- [ ] Список отсортирован по количеству действий (по убыванию)
- [ ] Показывает максимум 10 админов

#### ❌ Error Cases
- [ ] При ошибке загрузки появляется toast с ошибкой
- [ ] UI не "зависает" на loading
- [ ] Фильтры остаются применённые после ошибки

## 🤖 Bot Management

### Функциональность
- Просмотр статуса TTS сервера
- Мониторинг WebSocket соединений
- Статус платформ (Twitch, VK Live, YouTube)
- Мониторинг системных ресурсов (CPU, память, аптайм)
- Auto-refresh каждые 10 секунд

### Чек-лист

#### ✅ Загрузка данных
- [ ] Страница загружается без ошибок
- [ ] Все карточки отображаются (TTS, WebSocket, Платформы, Система)
- [ ] Кнопка "Обновить" работает
- [ ] Loading spinner показывается при обновлении

#### ✅ TTS Сервер
- [ ] Отображается статус (✅ Подключен / ❌ Ошибка / ⚠️ Деградирован)
- [ ] Показывается движок (gTTS / F5-TTS)
- [ ] Длина очереди отображается корректно
- [ ] Процент ошибок показывается
- [ ] Время последнего синтеза отображается

#### ✅ WebSocket Соединения
- [ ] Количество активных соединений отображается (число)
- [ ] Использование памяти показывается (формат: "45 MB")
- [ ] Аптайм отображается (формат: "2 days")

#### ✅ Платформы
- [ ] **Twitch:**
  - [ ] Статус отображается (✅ / ❌)
  - [ ] Bot username видно
  - [ ] Количество каналов показано
  - [ ] Дата истечения токена (в зелёном/жёлтом цвете)

- [ ] **VK Live:**
  - [ ] Статус отображается
  - [ ] Дата истечения токена видна
  - [ ] Предупреждение если близко к истечению

- [ ] **YouTube:**
  - [ ] Статус отображается
  - [ ] Все компоненты отрисовались правильно

#### ✅ Системные ресурсы
- [ ] CPU использование отображается в процентах
- [ ] Память показывается (формат: "512 MB / 2 GB")
- [ ] Аптайм сервера отображается (формат: "45 days")

#### ✅ Auto-refresh
- [ ] При открытии страницы данные обновляются
- [ ] Данные обновляются каждые 10 секунд (без ручного клика)
- [ ] При закрытии страницы interval очищается

#### ❌ Error Cases
- [ ] При ошибке загрузки показывается toast
- [ ] Страница не падает при ошибке
- [ ] Предыдущие данные остаются видны

## ⚠️ Error Logs

### Функциональность
- Просмотр системных логов в реал-тайме
- Фильтрация по уровню (ERROR, WARNING, INFO)
- Фильтрация по модулю (API, Auth, TTS, DB, WebSocket)
- Выбор количества строк (50-500)
- Статистика ошибок, предупреждений, информационных сообщений

### Чек-лист

#### ✅ Загрузка логов
- [ ] Логи загружаются при открытии страницы
- [ ] Отображается правильное количество логов
- [ ] Каждый лог имеет цвет (красный/жёлтый/синий/серый)
- [ ] Каждый лог имеет иконку и статус

#### ✅ Фильтр "Уровень"
- [ ] Dropdown работает
- [ ] Фильтр "Ошибки (ERROR)" показывает только ошибки
- [ ] Фильтр "Предупреждения (WARNING)" показывает только WARNING
- [ ] Фильтр "Информация (INFO)" показывает только INFO
- [ ] Фильтр "Все" показывает все логи

#### ✅ Фильтр "Модуль"
- [ ] Dropdown заполняется
- [ ] Фильтр по модулю работает (если в логах есть эти модули)
- [ ] Логи фильтруются по наличию текста в содержимом

#### ✅ Фильтр "Строк"
- [ ] Dropdown работает (50, 100, 200, 500)
- [ ] При смене количества логи перезагружаются
- [ ] Отображается правильное количество строк

#### ✅ Таблица логов
- [ ] Логи отображаются с цветовой кодировкой:
  - [ ] ❌ ERROR - красный
  - [ ] ⚠️ WARNING - жёлтый
  - [ ] ℹ️ INFO - синий
  - [ ] • LOG - серый
- [ ] Текст логов полностью видим (без обрезки)
- [ ] Скроллинг работает для большого количества логов
- [ ] `max-h-96` (высота блока) не мешает восприятию

#### ✅ Статистика
- [ ] Карточки со статистикой отображаются:
  - [ ] Количество ошибок (красная цифра)
  - [ ] Количество предупреждений (жёлтая цифра)
  - [ ] Количество информационных (синяя цифра)
- [ ] Числа обновляются при фильтрации

#### ✅ Кнопка обновления
- [ ] Кнопка "Обновить" работает
- [ ] Loading spinner показывается
- [ ] Логи перезагружаются

#### ❌ Error Cases
- [ ] При ошибке загрузки показывается toast
- [ ] Если логов нет - показывается "Нет логов с выбранными фильтрами"

## 🐛 Known Issues

### Потенциальные проблемы для проверки

1. **N+1 Queries в System Logs**
   - [ ] Проверить что в `get_system_logs` не происходит N+1 для user lookups
   - [ ] Каждое обновление админа требует отдельного query?

2. **Large Dataset Performance**
   - [ ] Если в БД 10000+ логов - страница медленная?
   - [ ] Pagination помогает с производительностью?

3. **WebSocket Refresh в Bot Management**
   - [ ] Auto-refresh может ли привести к утечке памяти?
   - [ ] При открытии/закрытии - interval правильно очищается?

4. **File Size для Backup**
   - [ ] Очень большая БД (>1GB) может зависнуть на backup?
   - [ ] Есть ли timeout для операций?
