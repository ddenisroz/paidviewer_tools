# Исправления после тестирования проекта

## Обзор
После тестирования проекта были выявлены и исправлены критические проблемы интеграции между фронтендом и бэкендом.

## 🔧 Исправленные проблемы

### 1. ✅ Toggle авторизации в гостевом режиме
**Проблема:** После отключения интеграции и перехода в гостевой режим, повторное нажатие toggle не возвращало вызов авторизации.

**Исправление:**
- **Файл:** `frontend/src/components/layout/Header.jsx`
- **Изменения:**
  - Исправлена логика `handleTwitchToggle` и `handleVkToggle`
  - Добавлена проверка: при включении интеграции в гостевом режиме очищается флаг `guestModeEnabled` и запускается процесс авторизации через `setIsRedirecting(true)`
  - Теперь переключение из гостевого режима корректно возвращает пользователя к авторизации

### 2. ✅ Проверка whitelist в TTS
**Проблема:** Отсутствовала проверка на наличие пользователя в whitelist при использовании команды TTS.

**Исправления:**
- **Файл:** `bot-service/main.py`
- **Изменения:**
  - Добавлен whitelist функционал в класс `Bot`:
    - `whitelist_enabled` - флаг включения whitelist
    - `whitelist_users` - список разрешенных пользователей
    - `is_user_whitelisted()` - метод проверки пользователя
  - В команду `!tts` добавлена проверка whitelist перед обработкой
  - Добавлены API эндпоинты для управления whitelist:
    - `GET /api/bot/whitelist` - получение состояния whitelist
    - `POST /api/bot/whitelist/toggle` - включение/отключение whitelist
    - `POST /api/bot/whitelist/add` - добавление пользователя
    - `DELETE /api/bot/whitelist/remove` - удаление пользователя

### 3. ✅ 404 ошибка /api/chat/messages
**Проблема:** Фронтенд вызывал несуществующий эндпоинт `/api/chat/messages`, что приводило к множественным 404 ошибкам и перегрузке системы.

**Исправления:**
- **Файл:** `bot-service/main.py`
- **Изменения:**
  - Добавлен эндпоинт `GET /api/chat/messages` для получения истории сообщений чата
  - Добавлено хранилище сообщений `recent_messages` в класс `Bot`
  - Добавлен метод `add_message()` для сохранения сообщений в историю
  - В команду `!tts` добавлено сохранение сообщений с полными метаданными
  - Ограничена история до 100 последних сообщений для оптимизации памяти

### 4. ✅ Функции управления стримом
**Проблема:** Не работали функции изменения названия стрима и категории.

**Исправления:**
- **Файл:** `bot-service/main.py` 
- **Изменения:**
  - Проверены и исправлены эндпоинты:
    - `POST /api/twitch/stream/title` - обновление названия стрима
    - `POST /api/twitch/stream/category` - обновление категории стрима  
  - Добавлен новый эндпоинт `GET /api/twitch/categories` для поиска категорий Twitch
  - Исправлена функция `get_access_token()` для корректного получения токенов из cookies и headers
  - Улучшена обработка ошибок и логирование
