# 🔧 Исправления проблем

## Дата: 14 ноября 2025

---

## ✅ Исправленные проблемы

### 1. Ошибка загрузки TTS настроек
**Проблема:** `Cannot read properties of undefined (reading 'enabled_platforms')`

**Причина:** Бэкенд недоступен, `response.data.data` возвращает `undefined`

**Решение:**
- Добавлена проверка существования `response?.data?.data`
- Добавлена проверка существования `settings.enabled_platforms`
- Ошибки логируются как warnings, а не errors
- Приложение продолжает работать с дефолтными значениями

**Файл:** `frontend/src/components/ChatCard.tsx`

---

### 2. Ошибка загрузки Twitch badges
**Проблема:** `SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON`

**Причина:** API возвращает HTML вместо JSON когда бэкенд недоступен

**Решение:**
- Добавлена проверка `Content-Type` заголовка
- Если получен HTML вместо JSON, используются пустые badges
- Ошибки логируются как warnings
- Фоновое обновление badges пропускается если бэкенд недоступен

**Файл:** `frontend/src/services/twitchBadges.ts`

---

### 3. Отсутствие кнопок стриков
**Проблема:** Кнопки +/- для настройки стриков не отображаются

**Причина:** Компонент застревает в состоянии загрузки когда бэкенд недоступен

**Решение:**
- Изменена логика проверки `isLoading` - loader показывается только при начальной загрузке
- Добавлено предупреждение когда config не загрузился
- Компонент теперь показывает UI даже если бэкенд недоступен

**Файл:** `frontend/src/components/drops/StreakSettings.tsx`
