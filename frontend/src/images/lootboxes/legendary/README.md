# Легендарные лутбоксы

## Требуемые файлы

Добавьте следующие картинки в эту папку:

- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opening3.png` - третий этап открытия
- `opening4.png` - четвертый этап открытия
- `opening5.png` - пятый этап открытия
- `opened.png` - открытый лутбокс

## Стиль

- **Цвет**: Золотой (#FBBF24)
- **Эффект**: Золотое пульсирующее свечение
- **Сложность**: Максимальный дизайн
- **Детали**: Максимум деталей и эффектов

## Примеры изменений

1. **closed.png**: Закрытый ящик с золотым свечением
2. **opening1.png**: Трещины с золотым светом
3. **opening2.png**: Больше трещин, золотые частицы
4. **opening3.png**: Почти открыт, усиление золотых эффектов
5. **opening4.png**: Почти полностью открыт, яркое золотое свечение
6. **opening5.png**: Почти открыт, максимальное золотое свечение
7. **opened.png**: Открыт, видны легендарные золотые награды
