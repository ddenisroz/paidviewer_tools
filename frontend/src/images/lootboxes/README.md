# Папки для картинок лутбоксов

## Структура папок

```
lootboxes/
├── common/          # Обычные лутбоксы (3-4 картинки)
├── rare/            # Редкие лутбоксы (4-5 картинок)
├── epic/            # Эпические лутбоксы (5-6 картинок)
└── legendary/       # Легендарные лутбоксы (6-7 картинок)
```

## Требования к картинкам

### Размеры
- **Рекомендуемый размер**: 256x256 пикселей или больше
- **Формат**: PNG с прозрачным фоном
- **Соотношение сторон**: 1:1 (квадратные)

### Названия файлов
Каждая папка должна содержать картинки в следующем порядке:

#### Common (3-4 картинки)
- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opened.png` - открытый лутбокс

#### Rare (4-5 картинок)
- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opening3.png` - третий этап открытия
- `opened.png` - открытый лутбокс

#### Epic (5-6 картинок)
- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opening3.png` - третий этап открытия
- `opening4.png` - четвертый этап открытия
- `opened.png` - открытый лутбокс

#### Legendary (6-7 картинок)
- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opening3.png` - третий этап открытия
- `opening4.png` - четвертый этап открытия
- `opening5.png` - пятый этап открытия
- `opened.png` - открытый лутбокс

## Цветовая схема по редкости

### Common (Обычный)
- **Цвет**: Серый (#6B7280)
- **Эффект**: Без свечения
- **Иконка**: ⭐

### Rare (Редкий)
- **Цвет**: Синий (#3B82F6)
- **Эффект**: Синее свечение
- **Иконка**: ⚡

### Epic (Эпический)
- **Цвет**: Фиолетовый (#9333EA)
- **Эффект**: Фиолетовое свечение
- **Иконка**: 💎

### Legendary (Легендарный)
- **Цвет**: Золотой (#FBBF24)
- **Эффект**: Золотое пульсирующее свечение
- **Иконка**: 👑

## Советы по созданию картинок

1. **Согласованность**: Все картинки в наборе должны быть в одном стиле
2. **Прозрачность**: Используйте прозрачный фон для лучшей интеграции
3. **Детали**: Чем выше редкость, тем больше деталей и эффектов
4. **Анимация**: Покажите прогресс открытия через изменения в картинке
5. **Размер**: Убедитесь, что все картинки одинакового размера

## Примеры изменений при открытии

### Закрытый лутбокс
- Полностью закрыт
- Минимальные детали
- Статичный вид

### Этапы открытия
- Постепенное появление трещин
- Светящиеся элементы
- Изменение формы
- Добавление частиц/эффектов

### Открытый лутбокс
- Полностью открыт
- Видны награды внутри
- Максимальные эффекты
- Светящиеся элементы

## Тестирование

После добавления картинок:
1. Откройте вкладку "🎨 Анимированные лутбоксы"
2. Нажмите на лутбокс для тестирования анимации
3. Проверьте, что все картинки загружаются корректно
4. Убедитесь, что анимация выглядит плавно
