# Эпические лутбоксы

## Требуемые файлы

Добавьте следующие картинки в эту папку:

- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия
- `opening3.png` - третий этап открытия
- `opening4.png` - четвертый этап открытия
- `opened.png` - открытый лутбокс

## Стиль

- **Цвет**: Фиолетовый (#9333EA)
- **Эффект**: Фиолетовое свечение
- **Сложность**: Высокий дизайн
- **Детали**: Много деталей и эффектов

## Примеры изменений

1. **closed.png**: Закрытый ящик с фиолетовым свечением
2. **opening1.png**: Трещины с фиолетовым светом
3. **opening2.png**: Больше трещин, магические частицы
4. **opening3.png**: Почти открыт, усиление магических эффектов
5. **opening4.png**: Почти полностью открыт, яркое свечение
6. **opened.png**: Открыт, видны фиолетовые магические награды
