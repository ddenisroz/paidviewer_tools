# Обычные лутбоксы

## Требуемые файлы

Добавьте следующие картинки в эту папку:

- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия  
- `opening2.png` - второй этап открытия
- `opened.png` - открытый лутбокс

## Стиль

- **Цвет**: Серый (#6B7280)
- **Эффект**: Без свечения
- **Сложность**: Простой дизайн
- **Детали**: Минимальные

## Примеры изменений

1. **closed.png**: Простой закрытый ящик
2. **opening1.png**: Появление первых трещин
3. **opening2.png**: Больше трещин, начало открытия
4. **opened.png**: Полностью открыт, видны награды
