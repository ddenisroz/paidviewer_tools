# TTS_TTV - Text-to-Speech для Twitch

Система озвучивания чата Twitch с поддержкой русского языка и защитой от DDoS атак.

## 🚀 Возможности

- **Озвучивание чата** - автоматическое озвучивание сообщений из Twitch чата
- **Русский TTS** - высококачественный синтез речи на русском языке
- **Управление голосами** - настройка голосов для разных пользователей
- **Защита от DDoS** - многоуровневая защита от атак
- **Real-time обновления** - WebSocket для мгновенных обновлений
- **Управление чатом** - заглушение/разглушение пользователей

## 🛠️ Установка

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🔧 Настройка

1. **Настройте Twitch интеграцию** в веб-интерфейсе
2. **Загрузите голосовые файлы** в `backend/voices/`
3. **Настройте параметры TTS** в дашборде
4. **Включите TTS** для вашего канала

## 🛡️ Безопасность

- **Rate Limiting** - ограничение частоты запросов
- **Security Middleware** - защита от SQL инъекций и XSS
- **IP Blocking** - автоматическая блокировка подозрительных IP
- **Logging** - полное логирование всех событий

## 📊 Мониторинг

- **Security API** - `/api/security/stats` для статистики
- **Health Check** - `/api/security/health` для проверки состояния
- **Logs** - все события в консоли сервера

## 🎯 Использование

1. Запустите backend и frontend
2. Войдите в систему через Twitch
3. Настройте голоса и параметры TTS
4. Включите озвучивание чата
5. Наслаждайтесь озвучкой сообщений!
