# 🧹 Скрипты очистки базы данных

Набор скриптов для безопасной очистки пользовательских данных при тестировании системы.

## 📋 Доступные скрипты

### 1. `clean_users_safe.py` - Безопасная очистка (РЕКОМЕНДУЕТСЯ)
**Самый безопасный и полнофункциональный скрипт**

```bash
cd bot_service
python clean_users_safe.py
```

**Особенности:**
- ✅ Создает backup перед очисткой
- ✅ Показывает подробную статистику
- ✅ Сохраняет важные настройки (whitelist, заблокированные боты, голоса)
- ✅ Интерактивные подтверждения
- ✅ Детальный отчет о проделанной работе
- ✅ Возможность восстановления из backup

**Что удаляет:**
- Пользователи и их профили
- Токены авторизации (Twitch, VK)
- Активные сессии
- Верификации гостевого режима
- Данные стримов
- Очередь YouTube видео

**Что сохраняет:**
- Заблокированные боты
- Whitelist каналов
- Голоса TTS
- Другие системные настройки

### 2. `clean_full_system.py` - Полная очистка системы
**Комплексная очистка БД + активных ботов в памяти**

```bash
cd bot_service
python clean_full_system.py
```

**Особенности:**
- 🤖 Останавливает всех активных ботов
- 🧠 Очищает состояние в памяти
- 💾 Очищает базу данных
- 📊 Подробная статистика по шагам
- ✅ Создает backup

**Использовать когда:**
- Нужна полная перезагрузка системы
- Боты "зависли" и не отключаются
- Требуется очистить все соединения

### 3. `clean_users_quick.py` - Быстрая очистка
**Для быстрого тестирования в процессе разработки**

```bash
cd bot_service
python clean_users_quick.py
```

**Особенности:**
- ⚡ Быстрое выполнение
- 🚫 Без backup (осторожно!)
- 🚫 Минимум подтверждений
- ✅ Сохраняет системные настройки

**Принудительное выполнение:**
```bash
python clean_users_quick.py --force
```

### 4. `clean_active_bots.py` - Только активные боты
**Очистка только ботов в памяти (без БД)**

```bash
cd bot_service
python clean_active_bots.py
```

**Когда использовать:**
- Боты не отвечают
- Нужно перезапустить только ботов
- БД не нужно трогать

## 🎯 Какой скрипт выбрать?

### Для обычного тестирования:
```bash
python clean_users_safe.py
```
- Безопасно, с backup
- Подробная информация
- Возможность отката

### Для быстрой разработки:
```bash
python clean_users_quick.py
```
- Быстро и просто
- Без лишних вопросов
- Только для dev среды

### При проблемах с ботами:
```bash
python clean_full_system.py
```
- Полная перезагрузка
- Очистка памяти + БД
- Решает большинство проблем

### Только боты зависли:
```bash
python clean_active_bots.py
```
- Только память
- БД остается нетронутой

## 📊 Что содержит база данных?

### Пользовательские данные (удаляются):
- **users** - Профили пользователей
- **user_tokens** - OAuth токены (Twitch, VK)
- **user_sessions** - Активные сессии
- **guest_verifications** - Коды верификации гостей
- **vk_guest_verifications** - VK верификации
- **stream_data** - Статистика стримов
- **youtube_queue** - Очередь YouTube видео

### Системные настройки (сохраняются):
- **blocked_bots** - Заблокированные боты
- **whitelisted_channels** - Разрешенные каналы
- **voices** - Голоса для TTS
- **muted_users** - Заглушенные пользователи
- **blocked_channels** - Заблокированные каналы

## 🔄 Восстановление данных

### Из backup:
```bash
# Найти backup файлы
ls bot_service/backups/

# Восстановить конкретный backup
cp bot_service/backups/backup_20231224_143022.db bot_service/core/data/app_data.db
```

### Проверка базы после восстановления:
```bash
# Быстрая проверка
python -c "
from core.database import get_db, User
db = next(get_db())
print(f'Пользователей: {db.query(User).count()}')
db.close()
"
```

## ⚠️ Важные замечания

### Безопасность:
- `clean_users_safe.py` всегда создает backup
- `clean_users_quick.py` НЕ создает backup
- Backup файлы хранятся в `bot_service/backups/`

### Порядок очистки:
1. Сначала связанные данные (токены, сессии)
2. Потом основные таблицы (пользователи)
3. Системные настройки остаются нетронутыми

### После очистки рекомендуется:
```bash
# Перезапустить bot_service
# Перезапустить tts_service  
# Обновить фронтенд (F5)
```

## 🐛 Решение проблем

### "База данных заблокирована":
```bash
# Остановить все сервисы
# Подождать 5 секунд
# Запустить скрипт очистки
```

### "Боты не останавливаются":
```bash
python clean_full_system.py
# Принудительная остановка всех ботов
```

### "Скрипт не может найти базу":
```bash
# Проверить пути
ls bot_service/core/data/app_data.db
ls bot_service/data/app_data.db
ls bot_service/database.db
```

### "Нет прав на создание backup":
```bash
mkdir -p bot_service/backups
chmod 755 bot_service/backups
```

## 📈 Статистика очистки

После каждой очистки скрипты показывают:
- Количество удаленных записей по таблицам
- Сохраненные настройки
- Примеры удаленных пользователей
- Путь к созданному backup
- Время выполнения операции

## 🚀 Автоматизация

### Быстрая очистка в CI/CD:
```bash
python clean_users_quick.py --force
```

### Скрипт для полного цикла тестирования:
```bash
#!/bin/bash
echo "🧹 Очистка системы..."
python clean_full_system.py --auto

echo "🚀 Запуск тестов..."
# запуск тестов

echo "✅ Тесты завершены"
```

---

💡 **Совет**: Для ежедневной разработки используйте `clean_users_safe.py`. Для быстрых итераций - `clean_users_quick.py`.
