## ⚠️ ОПАСНАЯ МИГРАЦИЯ

### ef43e0597ce7_remove_unused_empty_tables.py

**Статус:** 🔴 **ОПАСНАЯ - НЕ ПРИМЕНЯТЬ!**

**Проблема:**
Эта миграция пыталась удалить **активно используемые** таблицы:

```python
empty_tables = [
    'muted_users',
    'blocked_channels', 
    'vk_guest_verifications',  # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для гостевого режима VK!
    'channel_points',           # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для баллов канала!
    'channel_rewards',          # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для наград!
    'gambling_games',
    'points_transactions',      # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для транзакций!
    'reward_queue',             # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для очереди наград!
    'gambling_results',
    'chat_messages',
    'user_progression',
    'achievements',
    'donation_alerts',
    'user_achievements',
    'psychology_analysis',      # ❌ АКТИВНО ИСПОЛЬЗУЕТСЯ для аналитики!
    'lootboxes'
]
```

**Что могло произойти:**
- 💥 Потеря всех баллов канала пользователей
- 💥 Удаление всех созданных наград
- 💥 Потеря истории транзакций
- 💥 Поломка гостевого режима VK Live
- 💥 Потеря аналитических данных

**Почему создана:**
Видимо, разработчик посчитал эти таблицы "пустыми", но фактически они используются в production.

---

## ✅ Правильная миграция

Вместо опасной миграции была создана новая:

**20251029_remove_unused_tables.py**

Удаляет **ТОЛЬКО действительно неиспользуемые** таблицы:
- ✅ `muted_users` - не используется (есть `TTSBlockedUser`)
- ✅ `tts_settings` - дубликат (`TTSUserSettings` используется вместо него)
- ✅ `guest_verifications` - не реализовано для Twitch

## 📝 Уроки

1. **ВСЕГДА проверяйте** использование таблицы перед удалением
2. **НЕ полагайтесь** на то, что таблица "пустая" = "неиспользуемая"
3. **Тестируйте миграции** на staging перед production
4. **Делайте бэкапы** перед применением миграций удаления
