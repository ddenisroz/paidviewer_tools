# 🔐 Настройка админов

## Формат ADMIN_USERS

В файле `.env` настройте переменную `ADMIN_USERS` в следующем формате:

```env
ADMIN_USERS=platform:user_id,platform:user_id
```

### Примеры:

```env
# Twitch и VK Live админы
ADMIN_USERS=twitch:987654321,vk:20416992

# Только Twitch админы
ADMIN_USERS=twitch:987654321,twitch:123456789

# Только VK Live админы
ADMIN_USERS=vk:20416992,vk:555666777
```

## Как получить Platform User ID

### Twitch:
1. Зайдите в Twitch Developer Console
2. В разделе "OAuth" найдите свой User ID
3. Или используйте API: `https://api.twitch.tv/helix/users?login=your_username`

### VK Live:
1. Зайдите в VK Live
2. В URL или в настройках найдите свой User ID
3. Или используйте VK API для получения ID

## Проверка админских прав

Система автоматически проверяет админские права при:
- Авторизации через OAuth
- Создании новых пользователей
- Доступе к админским API

Логи проверки можно найти в логах приложения.

## Безопасность

- **НЕ** используйте никнеймы - они могут изменяться
- **ИСПОЛЬЗУЙТЕ** только числовые ID платформ
- Регулярно проверяйте список админов
- Храните `.env` файл в безопасности
