# 🚫 Система фильтрации слов для TTS

## ✅ **Что реализовано:**

### 🗄️ **База данных:**
- **Таблица `filtered_words`** - хранит заблокированные слова для каждого пользователя
- **Поля:** `id`, `user_id`, `word`, `platform`, `created_at`, `is_active`
- **Индексы** для быстрого поиска по пользователю, слову и платформе

### 🔧 **Бэкенд API:**
- **`GET /api/tts/filtered-words`** - получить список слов пользователя
- **`POST /api/tts/filtered-words`** - добавить слово в фильтр
- **`DELETE /api/tts/filtered-words/{word_id}`** - удалить слово из фильтра
- **`POST /api/tts/filtered-words/check`** - проверить текст на заблокированные слова

### 🤖 **Интеграция с ботами:**
- **Twitch бот** - проверяет сообщения перед озвучкой
- **VK Live бот** - проверяет сообщения перед озвучкой
- **Фильтрация** происходит по владельцу канала

### 🎨 **Фронтенд:**
- **Управление словами** - добавление/удаление через UI
- **Выбор платформы** - all, twitch, vk
- **Индикаторы загрузки** - показывает состояние операций
- **Валидация** - предотвращает дубликаты

## 🎯 **Как работает:**

1. **Пользователь добавляет слово** в фильтр через UI
2. **Слово сохраняется** в базе данных для этого пользователя
3. **При получении сообщения** бот проверяет фильтр владельца канала
4. **Если слово найдено** - сообщение не озвучивается
5. **Логируется** в консоль бота для отладки

## 🔍 **Особенности:**

- **Персональные фильтры** - каждый пользователь управляет своими словами
- **Платформенная фильтрация** - можно настроить для конкретных платформ
- **Регистронезависимый поиск** - слова приводятся к нижнему регистру
- **Частичное совпадение** - если слово содержится в тексте, сообщение блокируется

## 📝 **Примеры использования:**

- Заблокировать слово "реклама" для всех платформ
- Заблокировать слово "спам" только для Twitch
- Заблокировать слово "оффтоп" только для VK Live

## 🚀 **Результат:**

Теперь фильтрация слов работает **реально** - заблокированные слова не будут озвучиваться ботом, а не просто храниться в localStorage!
