# 🎁 Настройка дефолтного виджета лутбокса

Пошаговая инструкция по настройке виджета лутбокса с показом ника, награды и анимацией открытия.

## 🎯 Что показывает виджет

- **Ник пользователя** - кто открыл лутбокс
- **Полученную награду** - что выиграл пользователь
- **Редкость лутбокса** - common, rare, epic, legendary
- **Анимацию открытия** - кадры анимации с эффектами
- **Звуковые эффекты** - звук в зависимости от редкости

## 🚀 Быстрая настройка

### 1. Создайте дефолтную конфигурацию

1. Запустите `bot_service`:
   ```bash
   cd bot_service
   python main.py
   ```

2. Откройте фронтенд и войдите в систему

3. Перейдите в **Виджеты OBS** → **Лутбокс**

4. Настройте виджет по своему вкусу:
   - **Размер**: 500x400px (рекомендуется)
   - **Цвета**: настройте под свой стиль
   - **Анимация**: 3 секунды (рекомендуется)
   - **Эффекты**: включите частицы и свечение

5. Нажмите **Сохранить** - получите персональную ссылку

### 2. Добавьте в OBS

1. В OBS добавьте **Browser Source**
2. Вставьте полученную ссылку
3. Установите размеры: **500x400px**
4. Включите **"Shutdown source when not visible"**
5. Нажмите **OK**

### 3. Тестирование

1. Откройте виджет в браузере
2. Используйте тестовые кнопки для проверки анимаций
3. Убедитесь что все работает корректно

## 📡 Отправка событий

### Из Python кода:

```python

# Отправить событие всем пользователям
await send_lootbox_opened(
    username="Viewer123",
    rarity="legendary",
    reward="5000 баллов",
    user_id=None  # Всем пользователям
)

# Отправить событие конкретному пользователю

    username="Viewer123", 
    rarity="epic",
    reward="1000 баллов",
    user_id="user_456"  # Конкретному пользователю
)
```

## 🎮 Интеграция с системой наград

### Подключение к существующей системе:

1. **В коде открытия лутбокса** добавьте отправку события:
   ```python
   # После определения награды
   reward = determine_reward(rarity)
   
   # Отправить в виджет
   await send_lootbox_opened(
       username=user.username,
       rarity=rarity,
       reward=reward,
       user_id=str(user.id)
   )
   ```

2. **В системе дропов** добавьте триггер:
   ```python
   # При получении дропа
   if drop.rarity in ['common', 'rare', 'epic', 'legendary']:
       await send_lootbox_opened(
           username=user.username,
           rarity=drop.rarity,
           reward=drop.name,
           user_id=str(user.id)
       )
   ```

## 🎨 Кастомизация наград

### Изменение списка наград:

В файле `frontend/src/widgets/LootboxWidget/script.js` найдите функцию `getRandomReward()`:

```javascript
getRandomReward(rarity) {
    const rewards = {
        common: [
            "100 баллов", "Обычная награда", "Монета", 
            "Зелье здоровья", "Простой предмет"
        ],
        rare: [
            "500 баллов", "Редкая награда", "Золотая монета",
            "Зелье маны", "Магический предмет"
        ],
        epic: [
            "1000 баллов", "Эпическая награда", "Драгоценный камень",
            "Эликсир", "Легендарный предмет"
        ],
        legendary: [
            "5000 баллов", "Легендарная награда", "Мифический артефакт",
            "Божественный эликсир", "Уникальный предмет"
        ]
    };
    
    const rarityRewards = rewards[rarity] || rewards.common;
    return rarityRewards[Math.floor(Math.random() * rarityRewards.length)];
}
```

### Добавление своих наград:

1. Откройте файл `script.js`
2. Найдите функцию `getRandomReward()`
3. Добавьте свои награды в соответствующие массивы
4. Сохраните файл

## 🔧 Устранение проблем

### Виджет не появляется:
1. Проверьте URL в OBS
2. Убедитесь что bot_service запущен
3. Проверьте WebSocket подключение в консоли браузера

### Анимация не работает:
1. Проверьте настройки анимации
2. Убедитесь что включены эффекты
3. Проверьте длительность анимации

### Звук не воспроизводится:
1. Проверьте настройки звука в виджете
2. Убедитесь что браузер разрешает воспроизведение
3. Проверьте наличие звуковых файлов

### Награды не отображаются:
1. Проверьте что передается параметр `reward`
2. Убедитесь что функция `getRandomReward()` работает
3. Проверьте консоль браузера на ошибки
