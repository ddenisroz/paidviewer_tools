# Редкие лутбоксы

## Требуемые файлы

Добавьте следующие картинки в эту папку:

- `closed.png` - закрытый лутбокс
- `opening1.png` - первый этап открытия
- `opening2.png` - второй этап открытия  
- `opening3.png` - третий этап открытия
- `opened.png` - открытый лутбокс

## Стиль

- **Цвет**: Синий (#3B82F6)
- **Эффект**: Синее свечение
- **Сложность**: Средний дизайн
- **Детали**: Больше деталей чем у обычных

## Примеры изменений

1. **closed.png**: Закрытый ящик с синим свечением
2. **opening1.png**: Трещины с синим светом
3. **opening2.png**: Больше трещин, усиление свечения
4. **opening3.png**: Почти открыт, яркое синее свечение
5. **opened.png**: Открыт, видны синие награды
