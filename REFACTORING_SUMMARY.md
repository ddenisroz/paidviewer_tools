## Выполненные изменения

### 1. Созданы переиспользуемые хуки

#### `useAutoSave.js`
- Хук для автосохранения с дебаунсом и валидацией
- Использует стандартные React хуки (`useRef`, `useCallback`)
- Поддерживает опциональную валидацию перед сохранением
- Показывает понятные ошибки пользователю через `toast.error`

#### `useDropsConfig.js`
- Единая логика работы с конфигурацией drops
- Использует `@tanstack/react-query` для кеширования и синхронизации
- Оптимистичные обновления для мгновенного UI
- Автоматическая синхронизация между компонентами через события

#### `useChatScroll.js`
- Упрощенная логика автоскролла чата
- Использует `useLayoutEffect` для синхронного позиционирования
- Константы вынесены (SCROLL_THRESHOLD)
- Убраны костыли с множественными проверками scrollHeight
