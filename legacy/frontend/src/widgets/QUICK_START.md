# 🚀 Быстрый старт с виджетами

Теперь настройки виджетов интегрированы прямо в соответствующие разделы приложения!

## 📱 Настройка чат виджета

1. **Откройте главную страницу** (`/dashboard`)
2. **В карточке "ChatBox"** нажмите на иконку сообщения (💬) рядом с настройками
3. **Настройте виджет:**
   - Выберите платформы (Twitch, VK Live, объединенный)
   - Настройте внешний вид (цвета, шрифты, размеры)
   - Выберите фильтр сообщений
4. **Сохраните конфигурацию** и скопируйте URL для OBS

## 🎁 Настройка лутбокс виджета

1. **Откройте страницу дропов** (`/dashboard/drops`)
2. **Перейдите на вкладку "Виджет"**
3. **Настройте анимацию:**
   - Размеры виджета
   - Длительность анимации
   - Эффекты (частицы, свечение, звук)
   - Цвета по редкостям
4. **Сохраните конфигурацию** и скопируйте URL для OBS

## ⚡ Настройка триггеров дропов

1. **На той же странице дропов** перейдите на вкладку **"Триггеры"**
2. **Создайте триггеры:**
   - **Донаты** - по сумме доната
   - **Стрики** - по дням присутствия
   - **Сообщения** - по количеству сообщений
   - **Пользовательские** - любые условия
3. **Или загрузите предустановки** - готовые триггеры

## 🔧 Добавление в OBS

1. **Добавьте Browser Source** в OBS
2. **Вставьте скопированный URL** виджета
3. **Установите размеры** (ширина × высота)
4. **Включите "Shutdown source when not visible"** для оптимизации

## 🎯 Готово!

Теперь у вас есть:
- ✅ **Чат виджет** с настройками прямо в чате
- ✅ **Лутбокс виджет** с настройками в дропах  
- ✅ **Триггеры дропов** для автоматических наград
- ✅ **Удобная настройка** без лишних страниц

Все настройки сохраняются персонально для каждого пользователя! 🎉
